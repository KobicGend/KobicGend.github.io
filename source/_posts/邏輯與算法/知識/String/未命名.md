## [ABC434F - Concat (2nd)](https://atcoder.jp/contests/abc434/tasks/abc434_f)

- $N$ strings $S_i$.
- Find the second lexicographically smallest string when concatenating $S_i$ in any order.

Let $S'_1,S'_2,\dots,S'_N$ be the result of sorting in the order defined by $X<Y$ iff $XY<YX$.

- If $N=2$, then the answer is $S'_2S'_1$.
- If there exists an integer $1 \le i < N$ such that $S'_i S'_{i+1}=S'_{i+1}S'_i$, then the answer is the string obtained by concatenating the strings in $S'$ in order.
- If the answer is undetermined up to this point, the answer is the lexicographically smaller of the following strings.
    - $S'_1S'_2 \dots S'_{N}S'_{N-1}$
    - $S'_1S'_2 \dots S'_{N-1}S'_{N-2}S'_N$
    - Proof:
        - First, any permutation of inversion number $2$ or greater is not applicable for the answer. This is because reducing the inversion number always yields a lexicographically smaller string.
        - Next, consider two strings $S'_1S'_2 \dots S'_{N-1}S'_N$ and $S'_1S'_2 \dots S'_{N}S'_{N-1}$. Since we can obtain them, any strings whose prefix is not $S'_1S'_2 \dots S'_{N-2}$ cannot be the answer.
