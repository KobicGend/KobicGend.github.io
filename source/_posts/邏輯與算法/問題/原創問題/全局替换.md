兹有一篇文章 $n$ 个字符串，第 $i$ 个字符串有 $a_{i}$ 个字符 `#`，你希望使用 Word 中的「全局替换」功能若干次，以改变 `#` 的数量，使得第 $i$ 个字符串有 $b_{i}$ 个 `#`。判断是否可行，如果可行，最小化操作次数。

全局替换功能的形式化描述：
- 任意选择两个字符串 $s,t$（这两个字符串可以包含任意字符，不局限于 `#`），对于这篇文章的每一个字符串，从前向后遍历，如果某个子串恰好为串 $s$，则将其删去，并在原位置插入串 $t$。
- 注意：在插入串 $t$ 后，将从 $t$ 后面的第一个字符接着遍历，而不会遍历到 $t$ 中的字符。例如选择 $s$ 串为 `##`，$t$ 串为 `#`，对于字符串 `###`，在进行一次替换后将变为 `##`，而不是 `#`。

数据范围：$n \leqslant 3 \times 10^{5},\ a_{i} \leqslant 10^{9}$。保证每个 $a_{i}$ 互不相同。

| Input | Output |
| ----- | ------ |
| 3     | 3      |
| 1 2 3 |        |
| 2 3 4 |        |
