## 加法

将片外 RAM 的 1000H 单元开始的 100 个字节的数据相加，结果存放于 R7 R6 中。

```
	ORG 0000H
	LJMP MAIN

	ORG 0100H
MAIN:
	MOV DPTR, #1000H
	MOV R2, #100
	MOV R6, #00H
	MOV R7, #00H
	
LOOP:
	MOVX A, @DPTR
	ADD A, R6
	MOV R6, A
	
	MOV A, R7
	ADDC A, #0
	MOV R7, A
	
	INC DPTR	
	DJNZ R2, LOOP
	
	SJMP $
END
```

```cpp
#include <reg51.h>
#include <absacc.h>
void main() {
	unsigned char i, hi = 0, lo = 0;
	for (i = 0; i < 5; i++) {
		XBYTE[0x1000 + i] = 100;
		hi = hi + XBYTE[0x1000 + i];
		if (CY == 1) { 
			lo = lo + 1; 
			CY = 0;
		} 
	}
	DBYTE[0x40] = lo;
	DBYTE[0x41] = hi;
	DBYTE[0x07] = DBYTE[0x40]; 
	DBYTE[0x06] = DBYTE[0x41];
	while (1);
}
```

## 片内外传送

给片内 RAM 的 40H～4FH 的 16 个字节赋初值 FFH，并将其内容传送到片外 RAM 的 2000H 单元处开始的位置，最后把 RAM 清零。

```
	ORG 0000H
	LJMP MAIN
	
	ORG 0100H
MAIN: 
	MOV DPTR, #2000H
	MOV R0, #40H
	MOV R2, #16
	
LOOP:
	MOV A, #0FFH
	MOV @R0, A
	MOVX @DPTR, A
	MOV A, #0
	MOVX @R0, A
	
	INC DPTR
	INC R0   
	
	DJNZ R2, LOOP

	SJMP $
END
```

```C
#include <reg51.h>
#include <absacc.h>
void main() {
	unsigned char i;
	for (i = 0; i < 16; i++) {
		DBYTE[0x40 + i] = 0xff;
		XBYTE[0x2000 + i] = DBYTE[0x40 + i];
		DBYTE[0x40 + i] = 0;
	}
	while (1);
}
```

## 延时

延时 10ms。设系统时钟频率 12MHz。时钟周期 1/12MHz，机器周期 $12\times1/12$MHz = 1μs。

## TAB 查表

一位十六进制数转换成 8 段式数码管显示码，设十六进制数放于 R2 中，要求转换的结果放回 R2 中。

```
	ORG 0200H

CONVERT1: 
	MOV DPTR, #TAB         ; TAB 首地址
	MOV A, R2              ; 偏移量
	MOVC A, @A+DPTR
	MOV R2, A
	RET
	
CONVERT2:
	MOV A, R2
	ADD A, #02H            ; TAB 首地址
	MOVC A, @A+PC
	MOV R2, A              ; PC 现在在这里, +2 后是表格起点
	RET
	
TAB: 
	DB 3FH, 06H, 5BH, 4FH, 66H, 6DH, 7DH, 07H
	DB 7FH, 67H, 77H, 7CH, 39H, 5EH, 79H, 71H 
	; 一位十六进制数 0～9、A、B、C、D、E、F 的 8 段式数码管的共阴极显示码
```

## 开关控制二极管

利用单片机的 P0 口接 8 个发光二极管，P1 口接 8 个开关，编程实现，当开关动作时，对应的发光二极管亮或灭。

为什么 P0 口有个上拉电阻？

- P0 口内部没有上拉电阻，无法输出这个信号；
- 上拉电阻可以增加输出电压，带动需要电力驱动的设备发光二极管。

```
	ORG 0100H
	
	MOV P1, #0FFH  ; 11111111
LOOP:
	MOV A, P1
	MOV P0, A
	SJMP LOOP
	
END
```

```c
#include <reg51.h>
void main() {
	P1 = 0xff;
	while (1) {
        P0 = P1;
    }
}
```

## 短周期 方式 2 生成方波

设系统时钟频率为 12MHZ，用定时/计数器 T0 编程实现从 P1.0 输出周期为 500μs 的方波。

- 时钟周期 1μs，250μs 翻转一次。
- 初值 $2^{8} - 250 = 6$。
- 采用方式 2，方式 2 会把初值存起来，不是高低位。

### 中断方式
 
```
	ORG 0000H
	LJMP MAIN
	
; 中断
	ORG 000BH  ; T0中断地址
	LJMP INTER
	
	ORG 0100H
	
INTER:
	CPL P1.0
	RETI	
	
; 主函数
MAIN:
	MOV TMOD, #02H  ; 模式2
	MOV TH0, #06H   ; 初值 
	MOV TL0, #06H   ; 初值
	SETB EA    ; Enable All bits
	SETB ET0   ; Enable Timer 0 Interrupt
	SETB TR0   ; Timer 0 Run control. Start
	
	SJMP $	
END	
```

```C
#include <reg51.h>
sbit P1_0 = P1^0;
void time0_int(void) interrupt 1 {  // T0中断号1
	P1_0 = !P1_0;
}
void main() {
	TMOD = 0x02;
	TH0 = 0x06;
	TL0 = 0x06;
	EA = 1;
	ET0 = 1;
	TR0 = 1;
	while (1);
}
```

## 长周期 方式 1 生成方波

### 软件计数

设系统时钟频率为 12MHZ，从 P1.1 输出周期为 1s 的方波。

- 时钟周期 1μs，500ms 翻转一次。
- T0 10ms = 10000μs 翻转一次，初值 65536-10000 = 55536 = D8F0，存高低位。
- 用 R2 循环 50 次，50 次后再让 T0 翻转。

```
	ORG 0000H
	LJMP MAIN
	
	ORG 000BH
	MOV TH0, #0D8H  ; 重置初值
	MOV TL0, #0F0H
	DJNZ R2, NEXT
	MOV R2, #50 ; 重置
	CPL P1.1
NEXT:
	RETI

	ORG 0100H
MAIN:
	MOV TMOD, #01H
	MOV TH0, #0D8H
	MOV TL0, #0F0H
	MOV R2, #50
	SETB EA 
	SETB ET0
	SETB TR0 
	SJMP $
END	
```

```c
#include <reg51.h>
int i;
sbit P1_1 = P1^1;
void time0_int(void) interrupt 1 {
    TH0 = 0xD8;
    TL0 = 0xF0;
    i--;
    if (!i) {
        i = 50;
        P1_1 = !P1_1;
    }
}
void main() {
    TMOD = 1;
    TH0 = 0xD8;
    TL0 = 0xF0;
    i = 50;
    EA = 1;
    ET0 = 1;
    TR0 = 1;
    while (1);
}
```

### 硬件级联

设系统时钟频率为 12MHZ，从 P1.1 输出周期为 1s 的方波。

- 时钟周期 1μs，500ms 翻转一次。
- T0 10ms = 10000μs 翻转一次，初值 65536-10000 = 55536 = D8F0。
- T0 每隔 20ms 踢一下 T1。
- T1 被踢 25 下之后，再执行翻转 P1.1 的操作，方式二。256 - 25 = 231 = E7。
- TMOD 设置 0110 0001B（T1 计数方式二，T0 定时方式一）

```
	ORG 0000H
	LJMP MAIN
		
	ORG 000BH
	MOV TH0, #0D8H  ; 重置初值
	MOV TL0, #0F0H
	CPL T1
	RETI
	
	ORG 001BH
	CPL P1.1
	RETI
	
	ORG 0100H
MAIN: 
	MOV TMOD, #61H
	MOV TH0, #0D8H 
	MOV TL0, #0F0H
	MOV TH1, #0E7H 
	MOV TL1, #0E7H
	SETB EA
	SETB ET0
	SETB ET1
	SETB TR0
	SETB TR1
	SJMP $
END	
```


## 双机通信

| 位序号 | D7  | D6  | D5    | D4    | D3  | D2  | D1  | D0  |
| --- | --- | --- | ----- | ----- | --- | --- | --- | --- |
| 符号  | SM0 | SM1 | SM2=0 | REN=1 | TB8 | RB8 | TI  | RI  |


```
	ORG 0000H
	LJMP MAIN
	
	ORG 0023H 
	LJMP INS  ; 地方不够用需要跳走
	
	ORG 0100H
MAIN:
	MOV SCON, #01010000B ; 设置串行口方式1，允许接收
	MOV TMOD, #20H     ; T1方式2
	MOV TL1, #0E6H     ; 设置波特率1200 方式2，自动重装
	MOV TH1, #0E6H 
	SETB EA            ; Enable All
	SETB ES            ; Enable Serial
	SETB TR1           ; Timer 1 Run

; 发送过程 (查询法)
LOOP0: 
	MOV P1, #0FFH ; #11111111B
    MOV A, P1    
    MOV SBUF, A   ; 发
    
LOOP1:
	JNB TI, LOOP1   ; while (!TI) 
	; 发送完毕 TI=1
    CLR TI 
    LJMP LOOP0
    
; 中断服务：接收过程 (中断法)
INS: 
	CLR EA     ; 拒绝接收任何新的中断请求
	CLR RI   
	MOV A, SBUF   ; 收
	MOV P2, A     ; 送到P2口显示
	SETB EA    ; 重新允许接收任何新的中断请求
	RETI  
```



## 键盘及消抖知识点总结

题目 1：简述单片机系统中机械式按键的工作原理。

1. 构造：键盘是一组按键开关，平时断开、按下闭合。
2. 电平变化：未按下为高电平、按下为低电平。
3. 识别方式：单片机通过定时或程序扫描的方式读取 I/O 口电平状态。

题目 2：什么是按键抖动？为什么要消除抖动？

1. 定义：机械触点的弹性作用，闭合和断开的瞬间不会立即生效，而是伴随一连串的电平波动。
2. 消除原因：若不消除抖动，单片机的高速处理能力会将这一连串的波动误认为多次按键输入，导致程序产生误动作。

题目 3：消除按键抖动通常有哪两种方法？请简要说明软件消抖的逻辑。

1. 消抖方法：硬件消抖、软件消抖。
2. 软件消抖逻辑：检测-延时-再次确认。
