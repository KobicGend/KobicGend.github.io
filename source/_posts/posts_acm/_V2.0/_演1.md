## 绪

**变换** 可以被理解为一种系统性的视角转换，从另一个角度看数组内的元素。**矩阵** 是描述线性变换的核心工具，我们通过一个固定的矩阵，将一个向量数组从一个坐标系下表示，转换到另一个坐标系下的新表示。

回忆矩阵乘法的定义：设 $\boldsymbol{A}$ 是一个 $N \times P$ 阶矩阵，$\boldsymbol{B}$ 是一个 $P \times M$ 阶矩阵，其乘积 $\boldsymbol{C} = \boldsymbol{A} \boldsymbol{B}$ 是一个 $N \times M$ 阶矩阵，矩阵 $\boldsymbol{C}$ 中位于第 $n$ 行、第 $m$ 列的元素 $C_{nm}$ 是通过计算矩阵 $\boldsymbol{A}$ 的第 $n$ 行与矩阵 $\boldsymbol{B}$ 的第 $m$ 列的内积 (Inner Product)，即
$$
C_{nm} = \sum_{k = 1}^{P} A_{nk} B_{km}
$$

简单来说，能从若干 $x$ 推出某个 $X_{i}$，将其反过来，用若干 $X$ 反推出某个 $x_{i}$，这过程就是反演。

形式化地，用矩阵描述这个关系。考虑一个由序列 $\lbrace x_{n} \rbrace_{n=1}^N$ 构成的 $N$ 维 **列向量** $\boldsymbol{x}^{\mathrm T} = [x_{1}, x_{2}, \dots, x_{N}]$，选取一个 $N \times N$ 阶的可逆矩阵 $\boldsymbol{T}$，通过左乘 $\boldsymbol{T}$，即对 $\boldsymbol{x}$ 做 **初等行变换** 得到一个新的列向量 $\boldsymbol{X} = \boldsymbol{T}\boldsymbol{x}$。
-   这个从 $\boldsymbol{x}$ 到 $\boldsymbol{X}$ 的过程，称为 **正演变换 (Forward Transform)**；
-   其逆过程，即从 $\boldsymbol{X}$ 恢复出原始 $\boldsymbol{x}$ 的过程 $\boldsymbol{x} = \boldsymbol{T}^{-1}\boldsymbol{X}$，称为 **反演变换 (Inverse Transform)**。

例如前缀和与差分就是一对反演关系，此外有二项式反演、子集反演和莫比乌斯反演等。

这两个过程的数学细节如下：
$$
\begin{array}{crclcl}
    \text{正演} & \displaystyle X_{n} = \sum_{m = 1}^{N} T_{nm} x_{m}  & \iff & \boldsymbol{X} = \boldsymbol{T} \boldsymbol{x} \\
    \text{反演} & \displaystyle x_{n} = \sum_{m = 1}^{N} T^{-1}_{nm} X_{m} & \iff & \boldsymbol{x} = \boldsymbol{T}^{-1} \boldsymbol{X}
\end{array}
$$

在正演中，$\boldsymbol{T}$ 的第 $n$ 行表明如何将原始向量 $\boldsymbol{x}$ 的所有元素进行加权求和，以混合出新的向量 $\boldsymbol{X}$ 中的第 $n$ 个元素 $X_n$。

(1) Zeta - Möbius 变换与一维前缀和
(2) Möbius 变换之 SoS DP
(3) Möbius 变换之 N 维前后缀和 & OR 卷积 & AND 卷积
(4) Walsh - Hadamard 变换 (WHT) & XOR 卷积
(5) Möbius 变换之数论 Möbius 变换 & Dirichlet 卷积 & GCD 卷积
(6) Möbius 变换之二项式反演
(7) Möbius 变换之容斥原理 & Min-Max 反演
(8) 离散傅立叶变换 DFT & 线性卷积


## Zeta - Möbius 变换

> 本节中的定义高度抽象，是对具体例子的归纳总结。建议不必在此处纠结过深，可以先看后面的实例，再返回阅读本节的定义。

我们平常说的「排序」，比如数字大小 1 < 2 < 3，任何两个不同的数字都可以比较大小。这是一种「完全」的排序。而 **偏序 (Partial Order) 集** 则是一种「部分」的、不那么严格的排序。在一个偏序集裡，并不是所有元素之间都能分出个先后高下。

Zeta - Möbius 变换用于计算偏序集上一个元素的所有上级（或下级）元素的某个函数值的总和，正反变换可以分别理解为累加与差分操作。

**Zeta 变换 (正演)** 计算的是一个累积值。对于集合 $A$，它的 Zeta 变换结果 $X(A)$，是 $A$ 的所有子集 $B$ 的某个函数值 $x(B)$ 的总和：
$$
X(A) = \sum_{B \subseteq A} x(B) 
$$

**Möbius 变换 (反演)** （习惯上也称为 Möbius 反变换）则是一个差分的过程。如果我们已知所有集合的累积值 $X$，利用 Möbius 变换就能反推出每个集合最初的 $x$：
$$
x(A) = \sum_{B \subseteq A} (-1)^{|A| - |B|} X(B) 
$$

此公式中的 $(-1)^{|A| - |B|}$ 项是关键，它源于容斥原理 (Inclusion-Exclusion Principle)，用于精确地修正每个 $X$ 的贡献。具体证明从略。

### 一维前缀和

一维数组的 **前缀和 (Prefix Sum)** 及其逆运算 **差分 (Difference)**，是 Zeta-Möbius 变换在线性序上最简单的体现。我们处理的集合是数组的下标 $\lbrace 1,2,\dots,N \rbrace$。

$$
X[k] = \sum_{n = 1}^{k} x[n]
\quad\iff\quad
x[n] = X[n] - X[n - 1]
$$

（以 $N = 3$ 为例）该变换过程的矩阵表示为 $\boldsymbol{X} = \boldsymbol{T} \boldsymbol{x}$，其中
$$
\boldsymbol{T}=
\begin{bmatrix}
1 & 0 & 0 \\ 
1 & 1 & 0 \\
1 & 1 & 1 \\
\end{bmatrix},
\qquad
\boldsymbol{T}^{-1}=
\begin{bmatrix}
1 & 0 & 0 \\
-1 & 1 & 0 \\
0 & -1 & 1 \\
\end{bmatrix}
$$
分别是下三角矩阵和下双对角矩阵。

```cpp
vector<ll> pre(n + 1);
for (int i = 0; i < n; i++) {
    pre[i + 1] = pre[i] + a[i];
}
// 查询[l, r)
auto get = [&](int l, int r) {
    return pre[r] - pre[l];
};
```

#### 经典差分问题——[VJspr12E - 差分求区间和 (Tea Tasting)](https://www.luogu.com.cn/problem/CF1795C)

> 有 $n$ 个人和 $n$ 杯茶，第 $i$ 个人每次会喝 $b_i$ 毫升的茶。第 $i$ 杯茶有 $a_i$ 毫升。总共会喝 $n$ 轮茶，第 $j$ 轮第 $i$ 个人会尝试喝第 $i+1-j$ 杯茶。喝的量为 $\min(a_{i+1-j},b_i)$ 毫升，并且使 $a_{i+1-j}$ 减少 $\min(a_{i+1-j},b_i)$。问 $n$ 轮后每个人喝了多少毫升茶。

考虑每杯茶对人的贡献。不难发现，第 $i$ 杯茶会对从第 $i$ 人开始的若干个人产生贡献。我们可以维护两个数组：
- $cnt_i$ 表示对第 $i$ 人产生完整贡献的次数。
- $ex_i$ 表示对第 $i$ 人产生的不完整贡献。

于是最终第 $i$ 人的答案就是 $cnt_i \times b_i + ex_i$。先求出 $a_i$ 的前缀和 $s_i$。对于每一杯茶，我们可以二分找到它的贡献终止的地方。设最后一个得到完整贡献的人下标为 $j$，则 $cnt_i$ 到 $cnt_j$ 整体加 $1$。$ex_{j+1}$ 要加上剩余的茶 $a_i - (s_j - s_{i-1})$。由于 $cnt$ 只需区间加和一次查询，差分即可。

```cpp
int a[N], b[N];
ll sum[N], cnt[N], ex[N];

void eachT() {
    int n = read();
    for (int i = 1; i <= n; i++) a[i] = read(), cnt[i] = ex[i] = 0;
    for (int i = 1; i <= n; i++) sum[i] = sum[i - 1] + (b[i] = read());

    for (int i = 1; i <= n; i++) {
        int r = lower_bound(sum + i, sum + n + 1, a[i] + sum[i - 1]) - sum - 1;
        cnt[i]++, cnt[r + 1]--;
        ex[r + 1] += a[i] - (sum[r] - sum[i - 1]);
    }  // [i,r]喝一次 剩下的给r+1

    for (int i = 1; i <= n; i++) {
        cnt[i] += cnt[i - 1];
        printf("%lld%c", cnt[i] * b[i] + ex[i], " \n"[i == n]);
    }
}
```

## Möbius 变换之子集和 (SoS) 问题

<!--- xleftrightarrow --->

> 在第一部分，我们建立了变换与反演的通用框架，并抽象地介绍了 Zeta - Möbius 变换。这篇文章中，我们将通过一个具体实例——**子集和问题 (Sum over Subsets, SoS) / N 维空间中的前缀和问题**，来深入理解 Zeta - Möbius 变换。

一个数的二进制表示可以看作是一个集合。这是位掩码 (Bitmask) 技巧，在状压 DP 中广泛使用。

如果一个问题涉及的全集包含 $N$ 个元素，我们可以用一个 $N$ 位的二进制数来表示它的任意一个子集。该数的第 $i$ 位（从右往左，从 0 开始计数）为 1，代表集合中包含第 $i$ 个元素；为 0 则代表不包含。

整数对应的位运算也可看作是对集合的操作，如

- 空集 $\varnothing$ 对应于 `0`，全集对应于 `-1`，即二进制都是 1；

- 交集 $a \cap b$ ——按位与 `a & b`；

- 并集 $a \cup b$ ——按位或 `a | b`；

- 补集 $\overline{a}$ ——按位取反 `~a` 或 `a ^ ((1 << n) - 1)`；

- 差集 $a \setminus b$ —— `a & (~b)`；

- 对称差 $a \Delta b$ ——按位异或 `a ^ b`；

- $t$ 是 $s$ 的子集 $t\subset s$ —— `(t | s) == s`；

- $t$ 是 $s$ 的超集 $t\supset s$ —— `(t & s) == s`；

- $s$ 的元素个数 $|s|$ —— `__builtin_popcountll(s)` 或 `s.count()`；

- `__builtin_ctzll`：末尾的 0，即对 lowbit 取 `__lg`；

- `__builtin_clzll`：开头的 0，用 31 减是 `__lg`。（复杂度都是 $\mathcal{O}(1)$，如果是 long long，函数名末尾加 ll，31 改成 63）


### 子集和 (SoS) 问题

> **题意** 给定一个长度为 $2^N$ 的数组 $x$，其下标 $0, 1, \dots, 2^N-1$ 对应了 $N$ 个元素构成的所有子集。希望计算另一个数组 $X$，使得 $X[s]$ 的值等于它所有子集 $t$ 对应的 $x[t]$ 的总和。$N \leqslant 22$。

将 Zeta - Möbius 变换中的集合关系用位掩码语言描述，
$$
X(S) = \sum_{T \subseteq S} x(T) 
\iff 
X[s] = \sum_{t \mid s = s} x[t]
$$
这直接将变换应用到了整数的位运算上。子集和问题的本质是 Zeta 正变换。

从算法竞赛角度，我们更关心如何快速求解这个问题。

##### 方法一 暴力枚举 3^N

暴力枚举是最直观的方法。对每一个集合 / mask `s`，我们都暴力状压 DP 去枚举它所有的子集 / submask `sub`。

```cpp
for (int s = 0; s < 1 << N; s++) {
    for (int sub = s; sub; sub = (sub - 1) & s) { // 降序遍历 s 的非空子集 sub
        X[s] += x[sub];
    }
    X[s] += x[0]; // 加上 s 的空子集 
}
```

时间复杂度是委员会公式 $\mathcal{O} \left[ \sum_{n=0}^{N} \binom{N}{n}2^{n} \right] = \mathcal{O}(3^{N})$，期望通过 $N = 17$ 的数据。

##### 方法二 SoS DP

###### 子集与超立方体

 $N$ 元集子集和与 $N$ 维前缀和是相互对应的，这是因为所有子集这个组合概念，可以被完美地映射为一个 $N$ **维超立方体 (Hypercube)** 的几何结构：（读者可以分别代入 $N = 2,3$ 理解下面的对应关系）

- 将 $N$ 元集的全部 $2^N$ 个子集对应为一个 $N$ 维超立方体的 $2^N$ 个顶点。

- 如何标记一个 $N$ 维超立方体的顶点呢？最自然的方式就是用一个 **$N$ 维的二进制坐标** $(b_{N-1}, b_{N-2}, \dots, b_0)$，其中每个 $b_i$ 要么是 0，要么是 1。这与我们用来表示子集的 **位掩码 (Bitmask)** 完全一致。例如，一个顶点坐标 $(1, 0, 1)$ 就代表了集合 $\{0, 2\}$。

- 超立方体的每一个维度（坐标轴），都对应着全集中的一个特定元素。沿着第 $i$ 根坐标轴从 0 移动到 1，就几何地对应着将第 $i$ 个元素加入集合这个操作。

这样，子集构成的空间便具象化为了一个 $N$ 维几何空间。

###### 子集和与高维前缀和 N 2^N

我们再看两种求和的定义。

- **子集和 (Sum over Subsets)** 定义为 $\displaystyle X(S) = \sum_{T \subseteq S} x(T)$，这里的核心是 **子集关系** $\subseteq$，$t \subseteq s$ 意味着对于每一个位，如果 $s$ 的该位是 0，那么 $t$ 的该位也必须是 0；如果 $s$ 的该位是 1， $t$ 的该位则可以是 0 或 1。

- $N$ **维前缀和 (N-dimensional Prefix Sum)** 定义为 $\displaystyle X(c_1, \dots, c_N) = \sum_{i_1 \leqslant c_1} \dots \sum_{i_N \leqslant c_N} x(i_1, \dots, i_N)$，这里的核心是 **坐标偏序** $\leqslant$，即一个点的坐标向量中的每一个分量都小于等于另一个点的对应分量。

在超立方体这个几何模型中，$t$ 是 $s$ 的子集这一关系，等价于顶点 $t$ 的每一个坐标分量都小于等于顶点 $s$ 的对应分量。于是，子集和问题在几何上被重新诠释为 $N$ 维前缀和问题：计算每个顶点上，由它和原点 $(0, 0, ..., 0)$ 所确定的超矩形内所有顶点的值的总和。

这启发我们，可以像计算二维前缀和那样 **逐个维度处理**，先算每行的前缀和，再在结果上算每列的前缀和。将一个高维度的复杂求和，分解为一系列简单的一维求和。

这一策略正是 SoS DP 算法的精髓。我们将把这个方法应用到 $N$ 维超立方体上，即 **逐个比特位** 地去构建最终的子集和。

 ###### SoS DP

设 $X[n][s]$ 表示只考虑最低的 $n+1$ 个比特位（即从第 $0$ 位到第 $n$ 位）的情况下，$s$ 的子集和。更形式化地，是满足如下条件的 $t$ 的 $x[t]$ 之和：
- $t \operatorname{\&} s = t$，且
- $t$ 的二进制表示只有最低 $n$ 位与 $s$ 不同，$t \oplus s < 2^{n}$。

我们来推导如何从 $X[n-1][s]$ 的状态计算出 $X[n][s]$，这对应于在超立方体上沿着第 $n$ 个维度进行处理。分析掩码 $s$ 的第 $n$ 个比特位：

情况一：$s$ 的第 $n$ 位是 $1$。此时，作为 $s$ 的子集 $t$，其第 $n$ 位可以是 $0$ 或 $1$。
-   如果 $t$ 的第 $n$ 位也是 $1$，那么 $t$ 与 $s$ 在此维度上无差异，这部分的贡献和就是 $X[n-1][s]$。
-   如果 $t$ 的第 $n$ 位是 $0$，那么 $t$ 实际上是 $s \oplus 2^n$ 的子集，并且 $t$ 与 $s \oplus 2^n$ 的差异只存在于最低的 $n$ 位。这部分的贡献和恰好是 $X[n-1][s \oplus 2^n]$。

情况二：$s$ 的第 $n$ 位是 $0$。由于 $t$ 必须是 $s$ 的子集，则 $t$ 的第 $n$ 位也必须是 $0$。这意味着在第 $n$ 这个维度上 $t$ 和 $s$ 没有差异。因此，计算 $X[n][s]$ 的约束条件与计算 $X[n-1][s]$ 的约束条件完全相同。

总得来说，转移为 $0,1 \to 1, \quad 0 \to 0$。

```cpp
X[-1] = x;   // 不太严谨的写法。。 表示没有考虑任何比特位 看得懂就行
for (int bit = 0; bit < N; bit++) {
	for (int s = 0; s < 1 << N; s++) {
		if (s >> bit & 1) {  // 情况一
			X[bit][s] = X[bit - 1][s] + X[bit - 1][s ^ (1 << bit)];
		} else {  // 情况二
			X[bit][s] = X[bit - 1][s];
		}
	}
}
```

滚动数组为：

```cpp
auto X = x;
for (int bit = 0; bit < N; bit++) {
	for (int s = 0; s < 1 << N; s++) {
		if (s >> bit & 1) {
			X[s] += X[s ^ (1 << bit)];
		}
	}
}
```

复杂度为 $\mathcal{O}(N \cdot2^{N})$，期望通过 $N = 22$ 的数据。

这就是 [最经典的 SoS DP](https://codeforces.com/blog/entry/45223)。

### 子集和问题的逆运算

在正向的子集和问题中，我们输入一个数组 $x$，输出一个子集和数组 $X$，其中 $X[s] = \sum_{t \subseteq s} x[t]$。现在我们求解它的逆问题：给定子集和数组 $X$，如何反向求解出那个原始的数组 $x$？

从第一部分的理论我们知道，这个反演过程由 Möbius 反演公式给出，我们依然关心如何快速求解。

正向的 SoS DP的核心思想是 **逐维累加** 贡献。在处理第 $i$ 维时，我们将该维度起点值累加到终点上。

```cpp
auto X = x;
for (int bit = 0; bit < N; bit++) {
	for (int s = 0; s < 1 << N; s++) {
		if (s >> bit & 1) {
			X[s] += X[s ^ (1 << bit)];
		}
	}
}
```

那么，逆向的过程自然就是 **逐维减去** 这些被累加上来的贡献，倒着操作上面的过程即可。

```cpp
auto x = X;
for (int bit = N - 1; bit >= 0; bit--) {
	for (int s = (1 << N) - 1; s >= 0; s--) {
		if (s >> bit & 1) {
			x[s] -= x[s ^ (1 << bit)];
		}
	}
}
```

仔细分析知循环顺序（升降序）不会改变最终的计算结果，这个代码可以改写为

```cpp
for (int bit = 0; bit < N; bit++) {
	for (int s = 0; s < 1 << N; s++) {
		if (s >> bit & 1) {
			x[s] -= x[s ^ (1 << bit)];
		}
	}
}
```

这样，我们得到了完整的正反快速变换的计算方法：

```cpp
template <typename T> 
void FMTOR(vector<T>& x, int o) {
    const int N = __lg(x.size());
    for (int bit = 0; bit < N; bit++) {
        for (int s = 0; s < 1 << N; s++) {
            if (s >> bit & 1) {
                x[s] += o * x[s ^ (1 << bit)];
            }
        }
    }
}
```

## Möbius 变换之 N 维前后缀和 & OR 卷积 & AND 卷积

### 子集和（$N$ 维前缀和）OR 卷积

$$
    c[k] = \sum_{n \mid m = k}^{} a[n] \cdot b[m]
    \xleftrightarrow
    [{\displaystyle x[t] = \sum_{s \mid t = t} (-1)^{|t| - |s|} X[s]}]
    {\displaystyle X[t] = \sum_{s \mid t = t} x[s]}
    C[k] = A[k] \cdot B[k]
$$

这个示意图按运算流程解读为：
1. 左侧 $c$ 是数组 $a$ 和 $b$ 的 **OR 卷积**，已知 $a$ 和 $b$ 直接计算 $c$ 的复杂度是 $\mathcal{O}(2^{2N})$。
2. 上方箭头表示正演，我们对原始数组 $a$ 和 $b$ 进行 **子集和变换**，得到在新域中的表示 $A$ 和 $B$，这可以用 SoS DP 实现，计算复杂度 $\mathcal{O}(N \cdot 2^{N})$。 
3. 右侧是变换域中的简易解，在变换后的新域中，原来那个复杂的卷积运算，被转化成了一个极其简单的逐元素乘积，计算复杂度 $\mathcal{O}(2^{N})$。 
4. 下方箭头表示反演，对 $C$ 执行子集和变换的逆运算，得到真正求解的 $c$，同样可以用 SoS DP 实现，计算复杂度 $\mathcal{O}(N \cdot 2^{N})$。 

```cpp
// 求子集和
template <typename T> 
void FMTOR(vector<T>& x, int o) {
    const int N = __lg(x.size());
    for (int bit = 0; bit < N; bit++) {
        for (int s = 0; s < 1 << N; s++) {
            if (s >> bit & 1) {
                x[s] += o * x[s ^ (1 << bit)];
            }
        }
    }
}

template <typename T>
vector<T> operator | (vector<T> f, vector<T> g) {  // 求或卷积
    FMTOR(f, 1);
    FMTOR(g, 1);
    for (int n = 0; n < f.size(); n++) {
        f[n] *= g[n];
    }
    FMTOR(f, -1);
    return f;
}
```

### 超集和（$N$ 维后缀和）AND 卷积

在子集和中，将每个数按位取反即是超集和。

$$
    c[k] = \sum_{n \& m = k}^{} a[n] \cdot b[m]
    \xleftrightarrow
    [{\displaystyle x[t] = \sum_{s \& t = t} (-1)^{|t| - |s|} X[s]}]
    {\displaystyle X[t] = \sum_{s \& t = t} x[s]}
    C[k] = A[k] \cdot B[k]
$$

```cpp
// 求超集和
template <typename T> 
void FMTAND(vector<T>& x, int o) {
    const int N = __lg(x.size());
    for (int bit = 0; bit < N; bit++) {
        for (int s = 0; s < 1 << N; s++) {
            // if (s >> bit & 1) {
            //     x[s ^ (1 << bit)] += o * x[s];
            // }
            if (s >> bit & 1 ^ 1) {
                x[s] += o * x[s ^ (1 << bit)];
            }
        }
    }
}

template <typename T>
vector<T> operator & (vector<T> f, vector<T> g) {  // 求与卷积
    FMTAND(f, 1);
    FMTAND(g, 1);
    for (int n = 0; n < f.size(); n++) {
        f[n] *= g[n];
    }
    FMTAND(f, -1);
    return f;
}
```

### XOR 卷积

**Walsh - Hadamard 变换 (WHT)** 不像傅里叶变换那样使用平滑的正弦波，而是使用值为 +1 和 -1 的方波（即 Walsh 函数）来分解信号。
$$
    c[k] = \sum_{n \oplus m = k}^{} a[n] \cdot b[m]
    \xleftrightarrow
    {\displaystyle X[m] = \sum_{n=0}^{N-1} (-1)^{n \diamond m} x[n]}
    C[k] = A[k] \cdot B[k]
$$
其中，$n \diamond m$ 代表索引 $n$ 和 $m$ 的二进制向量的 $\operatorname{GF}(2^{N})$ 上的 **点积**，$n \diamond m = \operatorname{popcount}(n \operatorname{\&} m)  \bmod 2$。

$\boldsymbol{H}_{N}$ 是 $N$ 阶 **Hadamard 矩阵**
$$
(\boldsymbol{H}_{N})_{i j} = (-1)^{i \diamond j}
\quad \iff \quad
\begin{cases}
\boldsymbol{H}_2 = \begin{bmatrix} 1 & 1 \\ 1 & -1 \end{bmatrix}
\\
\boldsymbol{H}_{2N} = \begin{bmatrix} \boldsymbol{H}_{N} & \boldsymbol{H}_{N}
\\
\boldsymbol{H}_{N} & -\boldsymbol{H}_{N} \end{bmatrix}
\end{cases}
$$
满足正交性即
$$
\boldsymbol{H}_{N} \boldsymbol{H}_{N}^{\mathrm T} = N \boldsymbol{I}_N 
\iff 
\boldsymbol{H}_{N}^{-1} = \dfrac{1}{N}\boldsymbol{H}_{N}^{\mathrm T}
$$
```cpp
template <typename T, typename U>
void WHT(vector<T>& x, U o) {
    const int N = x.size();
    for (int k = 1; k < N; k <<= 1) {
        for (int j = 0; j < N; j += k << 1) {
            for (int i = 0; i < k; i++) {
                auto& u = x[i + j];
                auto& v = x[i + j + k];
                tie(u, v) = pair(o * (u + v), o * (u - v));
            }
        }
    }
}

template <typename T>
vector<T> operator ^ (vector<T> f, vector<T> g) {  // 求异或卷积
    const int N = f.size();
    WHT(f, 1);
    WHT(g, 1);
    for (int n = 0; n < N; n++) {
        f[n] *= g[n];
    }
    WHT(f, Z(1) / 2);
    return f;
}
```

#### 模板：[ABC367G](https://atcoder.jp/contests/abc367/tasks/abc367_g)

正整数 $N,M,K$ および非負整数列 $A=(A_1,A_2,\ldots,A_N)$ が与えられます。
$$
    S = \sum_{\substack{\varnothing \ne S \subseteq \{ 1, \ldots, N \} \\ \lvert S \rvert \equiv 0 \pmod{M}}} \Bigg( \bigoplus_{n \in S} A_{n} \Bigg)^{K}
$$
を 998244353 で割った余りを求めてください。
制約：$1 \leqslant N,K \leqslant 2 \times 10^5$，$1 \leqslant M \leqslant 100$，$0 \leqslant A_{n} < 2^{20}$。

XOR 的 $K$ 次方没有良好性质，考虑枚举 XOR 的值 $v$。定义形式参量 $x$ 的乘法规则为 $x^n \times x^m = x^{n \oplus m}$，$y$ 的乘法规则是 $M$ 点圆周卷积，即 $y^a\times y^b=y^{(a+b)\bmod M}$，欲求
$$
    S = \sum_{v=0}^{V - 1} v^{k} [x^{v} y^{0}] \prod_{n=1}^{N}(1 + y \cdot x^{A_{n}})
$$

对于
$$
    g(x, y) = \prod_{n=1}^{N}(1 + y \cdot x^{A_{n}})
$$
先认为 $y$ 为常数，处理参量 $x$。直接做 WHT、对位乘后再反 WHT，复杂度 $\mathcal{O}(N V \log V)$，不能通过。

令 $f_{n}(x) = 1 + y \cdot x^{A_{n}}$，依定义，其 WHT
$$
F_{n}(x)
= \sum_{m = 0}^{V - 1} x^{m} [1 + y \cdot (-1)^{A_{n} \diamond m}]
$$
每一项的系数只有两种取值。

我们想知道对位乘的结果 $G(x)$，没有必要具体求出每一个 $F_{n}(x)$，只知道看 $G(x)$ 中每一项 $x^{m}$ 的系数，知道每种取值有多少个即可。对于 $0 \leqslant m < V$，设有 $\alpha_{m}$ 个 $n$ 满足 $A_{n} \diamond m$ 为奇数，$N - \alpha_{m}$ 个为偶数，则
$$
    \begin{aligned}
        G(x, y)
         & = \sum_{m = 0}^{V - 1} x^{m} 
         \prod_{n=1}^{N} \big[ 1 + y \cdot (-1)^{A_{n} \diamond m} \big]
        \\
         & = \sum_{m = 0}^{V - 1} x^{m} 
         \big[ (1 - y)^{\alpha_{m}} (1 + y)^{N - \alpha_{m}} \big] 
    \end{aligned}
$$

为求解 $\alpha_{m}$，考察 $h(x) = \displaystyle \sum_{n=1}^{N} x^{A_{n}}$ 的 WHT
$$
\begin{aligned}
H(x) 
&= \sum_{m = 0}^{V - 1} x^{m} \sum_{n=1}^{N} (-1)^{A_{n} \diamond m}
\\
&= \sum_{m = 0}^{V - 1} x^{m} \big[ -\alpha_{m} + (N - \alpha_{m}) \big]
\end{aligned}
$$
解得 
$$
\alpha_{m} = \frac{N - [x^{m}] H(x)}{2}
$$
先 $\mathcal{O}(V \log V)$ 计算 $H(x)$，再求解每个 $\alpha_{m}$，进而就能知道 $G(x, y)$ 的表达式。

再处理参量 $y$。考虑到圆周卷积的点数 $M$ 不大，可以 $\mathcal{O}(NM)$ 预处理 $(1 \pm y)$ 若干幂次的 $y^{0}$ 项系数，再 $\mathcal{O}(M^{2})$ 做一次 $M$ 点圆周卷积得到 $[y^{0}]G(x, y)$。

再做反变换，并取 $x^{v}$ 项系数做加权求和，就得到了最终结果。

```cpp
void solve() {
	int N, M, K;
	cin >> N >> M >> K;
	
	vector f1(N + 1, vector<Z>(M));  // (1 - y)^{i}
	vector f2(N + 1, vector<Z>(M));  // (1 + y)^{i}
	f1[0][0] = f2[0][0] = 1;
	for (int i = 1; i <= N; i++) {
		for (int m = 0; m < M; m++) {
			f1[i][m] += f1[i - 1][m] - f1[i - 1][(m - 1 + M) % M];
			f2[i][m] += f2[i - 1][m] + f2[i - 1][(m - 1 + M) % M];
		}
	}

	vector<int> h(V);
	for (int i = 0; i < N; i++) {
		int x;
		cin >> x;
		h[x]++;
	}
	WHT(h, 1);

	vector<Z> g(V);
	for (int i = 0; i < V; i++) {
		int x = (N - h[i]) / 2;
		for (int m = 0; m < M; m++) {
			g[i] += f1[x][m % M] * f2[N - x][(M - m) % M];
		}
	}
	WHT(g, Z(1) / 2);

	Z res = 0;
	for (int v = 0; v < V; v++) {
		res += qpow(Z(v), K) * g[v];
	}
	cout << res << endl;
};
```


**变式 1** 给定大小为 $N$ 的可重集 $A$，计算选出两个可以为空的不交子集使其异或和相等的方案数。$N,A_{n} \leqslant 10^{5}$。([2023 ICPC Jakarta K. Deck-Building Game](https://codeforces.com/problemset/problem/1906/K))

对于选出子集的并集 $S$，那么当 $S$ 的异或和为 0 时 $S$ 有贡献 $2^{|S|}$。定义形式参量 $x$ 的乘法规则为 $x^n \times x^m = x^{n \oplus m}$，欲求
$$
[x^0] \prod_{n = 1}^{N} (1 + 2x^{A_{n}})
$$

**变式 2** 给定两个数 $N,K$，以及一个长度为 $K$ 的整数数组 $(A_1,A_2,\cdots, A_K)$。两个人玩 Nim 游戏，游戏通过以下方式生成一个游戏：任意选择一个 $1\le M\le N$，生成 $M$ 堆石子，对于每一堆，其石子数是 $A$ 中任意一个数。求先手获胜的游戏数，答案对 $998244353$ 取模。$N,K,A_{n} \leqslant 2 \times 10^{5}$。([ABC212H](https://atcoder.jp/contests/abc212/tasks/abc212_h))

定义形式参量 $x$ 的乘法规则为 $x^n \times x^m = x^{n \oplus m}$，欲求
$$
\sum_{M = 1}^{N} \Bigg[ \sum_{k = 1}^{K} x^{A_{K}} \Bigg]^{M}
$$
其 WHT 为
$$
\sum_{m = 1}^{V} x^{m}\sum_{M = 1}^{N} \Bigg[ \sum_{k = 1}^{K} (-1)^{A_{K} \diamond m} \Bigg]^{M}
$$
记 $F_{m} = \displaystyle \sum_{k = 1}^{K} (-1)^{A_{K} \diamond m}$ 为 $\displaystyle \sum_{k = 1}^{K} x^{A_{K}}$ 的 WHT 的第 $m$ 项，$M > 1$ 时上式用等比数列求和化简为

$$
特别处理 $M = 1$ 的情形。

### 子集卷积——扩维 DP 思想

**例** ([CF2070F. Friends and Pizza](https://codeforces.com/contest/2070/problem/F)) 设披萨数量 $N$，披萨集合 $P = \{P_{0}, P_{1}, \dots, P_{N-1}\}$，每块披萨 $P_{n}$ 的片数 $a_{n}$，朋友数量 $M$，对于每个朋友 $m \in \{1, \dots, M\}$，有一个他喜欢的披萨集合 $S_{m} \subseteq P$。

Monocarp 邀请恰好两位不同的朋友，记为朋友 $n$ 和朋友 $m$ ($n \neq m$)，对于任意一块披萨 $P_{k} \in P$：
1.  如果 $P_{k} \notin S_{n}$ 且 $P_{k} \notin S_{m}$，即 $P_{k} \notin (S_{n} \operatorname{\mid} S_{m})$，Monocarp 吃掉所有 $a_{k}$ 片。
2.  如果 $P_{k}$ 恰好被一位朋友喜欢，即 $P_{k} \in (S_{n} \oplus S_{m})$，那位朋友吃掉所有 $a_{k}$ 片。
3.  如果 $P_{k} \in (S_{n} \operatorname{\&} S_{m})$：
	-   若 $a_{k}$ 是偶数，两位朋友平分，相安无事。
	-   若 $a_{k}$ 是奇数，两位朋友会吵架——Monocarp 不喜欢这种情况。

令 $D = \{P_{k} : a_{k} \text{ is odd}\}$ 为所有奇数片披萨的集合。对于任何一块奇数片的披萨，它不能同时被两个朋友 $(n, m)$ 都喜欢，可以表示为 $(S_{n} \operatorname{\&} S_{m}) \operatorname{\&} D = \varnothing$。

对于每一个可能的 $K$ (从 $0$ 到所有披萨的总片数 $\sum a_{n}$)，计算使得 Monocarp 恰好吃了 $K$ 片的选择两个不会吵架的朋友有多少种方式。

数据范围：
- $1 \leqslant N \leqslant 20$
- $2 \leqslant M \leqslant 5 \times 10^{5}$
- $1 \leqslant a_{n} \leqslant 2 \times 10^{4}$

**将无序对化为有序对**。把有序对的结果减去对角线 $(n,n)$ 的情形再除以 2 就得到无序对的结果。

我们不能去枚举所有有序对 $(n, m)$，而是要 **反过来**，对于每个可能的并集 $U \subseteq P$，我们去计算有多少个有效的有序对 $(n,m)$ 使得 $S_{n} \operatorname{\mid} S_{m} = U$。

设 $y_{U}$ 表示满足喜欢的披萨集合的并集恰好是集合 $U$，即 $S_{n} \operatorname{\mid} S_{m} = U$，且不会吵架即 $(S_{n} \operatorname{\&} S_{m}) \operatorname{\&} D = \varnothing$ 的有序朋友对 $(n, m)$ 的数量。

一旦我们求出了所有 $y_{U}$，就可以：
1.  对每个 $U$，计算 Monocarp 吃的片数 $K = (\sum a_{k}) - \sum_{P_{k}\in U} a_{k}$。
2.  将 $y_{U}$ 累加到对应 $K$ 的总数上。
3.  最后处理对角线 $(n,n)$ 情况并除以 2。

把每个人喜欢的披萨集合 $S_{n}$ **塞进桶 $x$ 里**，设 $x[S]$ 为喜欢披萨集合恰好为 $S$ 的朋友数量，即 $x[S] = \left| \left\{ n : S_{n} = S \right\} \right|$，那么
$$
y_{U} = \sum_{\substack{S \operatorname{|} T = U \\ (S \operatorname{\&} T) \operatorname{\&} D = \varnothing}} x[S] \cdot x[T]
$$
现在计算 $y_{U}$。

处理下标两种限制的 sigma 不大容易，为 $x[S]$ **扩维**，尝试 **把有两种限制的 sigma 转化为两个独立变量的 sigma**。设一个集合 $S$ 的 rank 为它包含的奇数片披萨的数量，即 rank(S) $= |S \operatorname{\&} D|$，那么不吵架条件 $(S \operatorname{\&} T) \operatorname{\&} D = \varnothing$ 等价于（*可以画 Venn 图验证*）
$$
\text{rank}(S \operatorname{\mid} T) = \text{rank}(S) + \text{rank}(T)
$$
设
$$
x_{p}[S] = 
\begin{cases}
x[S], &  \text{rank}(S) = p \\
 0, &  \text{rank}(S) \ne p
\end{cases} 
$$
那么
$$
\begin{aligned}
y[U]
&= \sum_{\substack{S \operatorname{|} T = U \\ (S \operatorname{\&} T) \operatorname{\&} D = \varnothing}} x[S] \cdot x[T]
\\
\iff y_{\text{rank}(U)}[U] &= \sum_{\substack{S \operatorname{|} T = U \\ \text{rank}(U) = \text{rank}(S) + \text{rank}(T)}} x_{\text{rank}(S)}[S] \cdot x_{\text{rank}(T)}[T]
\\
&= \sum_{\text{rank}(U) = \text{rank}(S) + \text{rank}(T)} \Bigg[ \sum_{S \operatorname{|} T = U} x_{\text{rank}(S)}[S] \cdot x_{\text{rank}(T)}[T] \Bigg]
\\
&= \sum_{\text{rank}(U) = \text{rank}(S) + \text{rank}(T)} (x_{\text{rank}(S)} \ast_{|} x_{\text{rank}(T)})[U]
\end{aligned}
$$
其中 $(x_{\text{rank}(S)} \ast_{|} x_{\text{rank}(T)})[U]$ 表示 $x_{\text{rank}(S)}$ 和 $x_{\text{rank}(T)}$ 的 OR 卷积的第 $U$ 项。外层循环枚举 $\text{rank}(U)$，内层循环枚举 $\text{rank}(S)$，做 OR 卷积，就能求出 $y$ 数组。

时间复杂度 $\mathcal{O}(N^{2}\cdot 2^{N})$，$N = 18$ 时 $\mathcal{O}(N^{2}\cdot 2^{N}) = \mathcal{O}(10^{8})$。

```cpp
void solve() {
    int N, M;
    cin >> N >> M;

    vector<int> s(M);
    for (int i = 0; i < M; i++) {
        string t;
        cin >> t;
        for (char c : t) {
            s[i] |= 1 << c - 'A';
        }
    }

    int D = 0;
    vector<int> a(N);
    for (int bit = 0; bit < N; bit++) {
        cin >> a[bit];
        if (a[bit] & 1) {
            D |= 1 << bit;
        }
    }

    vector X(N + 1, vector<ll>(1 << N, 0));
    for (int i = 0; i < M; i++) {
        X[__builtin_popcount(s[i] & D)][s[i]]++;
    }
    for (int i = 0; i <= N; i++) {
        FMTOR(X[i], 1);
    }

    vector Y(N + 1, vector<ll>(1 << N));
    for (int r = 0; r <= N; r++) {
        for (int p = 0; p <= r; p++) {
            for (int s = 0; s < (1 << N); s++) {
                Y[r][s] += X[p][s] * X[r - p][s];
            }
        }
        FMTOR(Y[r], -1);
    }

    vector<ll> y(1 << N);
    for (int i = 0; i < (1 << N); i++) {
        y[i] = Y[__builtin_popcount(i & D)][i];
    }

    for (int i = 0; i < M; i++) {
        if ((s[i] & D) == 0) {
            y[s[i]]--;
        }
    }

    int sum = accumulate(a.begin(), a.end(), 0);
    vector<ll> res(sum + 1);
    for (int mask = 0; mask < 1 << N; mask++) {
        int cnt = sum;
        for (int bit = 0; bit < N; bit++) {
            if (mask >> bit & 1) {
                cnt -= a[bit];
            }
        }
        res[cnt] += y[mask];
    }
    
    for (int i = 0; i <= sum; i++) {
        res[i] >>= 1;
        cout << res[i] << " ";
    }
    cout << "\n";
}
```

## Möbius 变换在数论中的应用 & Dirichlet 卷积 & GCD 卷积

*前置知识：[[数论]]*

### [2115A / 2116C - Gellyfish and Flaming Peony](https://codeforces.com/contest/2115/problem/A)

#### Description

给定一个包含 $N$ 个正整数的数组 $A$。任意次操作：选择两个索引 $n$ 和 $m$，然后将 $A_n$ 的值更新为 $\operatorname{GCD}(A_n, A_m)$。求出让数组中所有元素都相等所需的最少操作次数。

所有元素最终必然会相等，且等于整个初始数组的 GCD。问题的核心就变成了如何求得最小的 GCD。

#### Note 1 暴力 DP

看到 5000 考虑 $\mathcal O(N^{2})$ 的 DP。设 $f_{n, x}$ 表示前 $n$ 个数中至少需要选出几个数才能组合出 GCD 等于 $x$。复杂度 $\mathcal O(N V\log V)$，$V=5000$。

```cpp
const int V = 5001;
vector<int> f(V, inf);
for (int n = 0; n < N; n++) {
	auto nf = f;
	nf[a[n]] = 0;
	for (int x = 1; x < V; x++) {
		nf[gcd(x, a[n])] = min(nf[gcd(x, a[n])], f[x] + 1);
	} 
	f = nf;
}
cout << (f[d] + N - 1) << endl;
```

可以通过预处理 GCD 实现 $\mathcal O(V^{2}+N V)$：

```cpp
for (int x = 0; x < V; x++) {
	gcd[x][0] = gcd[0][x] = gcd[x][x] = x;
}
for (int x = 1; x < V; x++) {
	for (int y = 1; y < x; y++) {
		gcd[x][y] = gcd[y][x] = gcd[y][x % y];
	}
}
```

官方题解给出了本题的 Bonus 版本：Try to solve $N, A_{n} \leqslant 2 \times 10^5$ with only one test case. 设值域为 $V$，期望复杂度 $\mathcal{O}(V\log V)$。

---

#### **Note 2** 迭代

考虑到求得最小的 GCD 需要的数不会很多，事实上最大只会是 $\omega(V)=8$，即 $V$ 以内一个数的最大素因子个数。

我们采用迭代的方式求解。迭代 $t$ 轮次后得到：**恰好选出 $t$ 个数（允许重复），它们的 GCD 可能为哪些**。循环 $\omega(V)$ 轮次后就找出答案，每轮迭代期望复杂度 $\mathcal{O}(V\log V)$。

设 
- $f[i]$: 初始数组中数字 $i$ 的出现次数，$\displaystyle f(x) = \sum_{n=0}^{N} x^{a_{n}} = \sum_{n=0}^{V - 1} f[n] \cdot x^{n}$。
- $g_{t}[i]$: 迭代 $t$ 轮次后，数字 $i$ 当前是否可以被表示为若干个数的 GCD。
每一轮迭代需要用 $f$ 来更新 $g_{t}$，具体来说是 $g_{t}[i]$ 将被赋值为：是否有可能从 $f$ 中选一个数 $x$，再从 $g_{t - 1}$ 选一个数 $y$，且其最大公约数 $\gcd(x, y)=i$。

$x$ 和 $y$ 都一定是 $i$ 的倍数，枚举 $i$ 的倍数（两个 log），加上 gcd 的判断（一个 log），复杂度 $\mathcal{O}(V\log^{3} V)$。

总的复杂度 $\mathcal{O}(V\log^{3} V\omega(V))$，跑 2e5 的数据还是有点危险的。

---

#### **Note 3** 变换与反演

进一步优化，引入辅助数组
- $G_{t}[i]$ 表示：是否有可能从 $f$ 中选一个数 $x$，再从 $g_{t - 1}$ 选一个数 $y$，它们的最大公约数 $\gcd(x, y)$ 是 $i$ 的倍数。
这样 $x$ 和 $y$ 都一定是 $i$ 的倍数，通过枚举倍数在 $\mathcal{O}(V\log V)$ 的时间就能求出 $h$ 数组。

显然 $\displaystyle G_{t}[n]=\sum_{k} g_{t}[nk]$，为了反过来，用 $G_{t}$ 表示 $g_{t}$，就需要用到反演。

Zeta - Möbius Transform 用于计算偏序集上一个元素的所有上级（或下级）元素的某个函数值的总和。在这里我们将其应用到「倍数——因子」这个上下级关系，即
$$
\begin{aligned}
    \displaystyle x[n] &= \sum_{d = 1}^ {\infty} \mu[d] \cdot X[n d]
    \\
    \displaystyle X[n] &= \sum_{d = 1}^ {\infty} x[n d]
\end{aligned}
$$
因此得到
$$
\displaystyle g_{t}[n] = \sum_{k}\mu[k] \cdot G_{t}[n k]
$$
其中 $d \mid n$ 表示 $d$ 是 $n$ 的约数，莫比乌斯函数 $\mu[n] = \begin{cases} 1, & n = 1 \\ 0, & \exists d > 1, d^{2} \mid n \\ (-1)^{\omega(n)}, & \text{otherwise}\end{cases}$ 可以用欧拉筛线性预处理。

如果我们传入的参数 $n$ 是一个 Square Free Number，这种数由于仅存在 $0 / 1$ 的指数，所以可以用二进制表示，$x$ 函数是一个恰好仅与传入参数有关的式子，那么上式本质上就是 Zeta - Möbius 变换的一种特殊形式。

总的复杂度 $\mathcal{O}(V\log V \cdot\omega(V))$。

```cpp
vector<int> f(V);       // f[i]: 初始数组中数字 i 的出现次数
vector<int> g(V);       // g[i]: 数字 i 当前是否可以被表示出来

for (auto x : a) {
	f[x] = 1;
	g[x] = 1;
}

for (int t = 1; ; t++) {
	vector<int> G(V);
	for (int i = 1; i < V; i++) {
		int sumf = 0;
		int sumg = 0;
		for (int j = i; j < V; j += i) {
			sumf += f[j];
			sumg += g[j];
		}
		G[i] = sumf * sumg;
	}
	for (int i = 1; i < V; i++) {
		g[i] = 0;
		for (int k = 1; i * k < V; k++) {
			g[i] += mu[k] * G[i * k];
		}
	}
	if (g[d] > 0) {
		cout << (t + n - 1) << endl;
		return;
	}
}
```

---

#### **Note 4** 在变换域操作

有变换就必然有卷积与乘法的对应，在数论中，这个卷积是 GCD 卷积，
$$
    c[k] = \sum_{\gcd(n, m) = k}^{} a[n] \cdot b[m]
    \xleftrightarrow
    [{\displaystyle x[n] = \sum_{d = 1}^ {\infty} \mu[d] \cdot X[n d]}]
    {\displaystyle X[n] = \sum_{d = 1}^ {\infty} x[n d]}
    C[k] = A[k] \cdot B[k]
$$
上面讲解中的 $G_{t}$ 实际上是 $f$ 和 $g_{t - 1}$ GCD 卷积的变换域表示，一个域的卷积对应于另一个域的乘法，$G_{t}[k]=F[k]\cdot G_{t-1}[k]$；而从 $G_{t}$ 倒推 $g_{t}$ 的过程，实际做了一次反 Mobius 变换。

从这个角度看，没有必要每次循环都先正变换再反变换。直接一直在变换域做点值乘法，
$$
G_{t} = \underbrace{ F \ast F \ast \dots \ast F }_{t \text{ times}}
$$
然后只判断 $g_{t}[d]$ 这一项是否大于 0。

复杂度 $\mathcal{O}(V\log V+V\cdot\omega(V))$。

```cpp
vector<int> f(V);       // f[i]: 初始数组中数字 i 的出现次数
for (auto x : a) {
	f[x] = 1;
}

vector<int> F(V);   // f 的变换域表示，原代码的 sumf
for (int i = 1; i < V; i++) {
	for (int j = i; j < V; j += i) {
		F[i] += f[j];
	}
}
auto G = F;  // g[0] 的变换域表示，原代码的 sumg

for (int t = 1; ; t++) {
	for (int i = 1; i < V; i++) {
		G[i] *= F[i];  // 做一次卷积 g[t] = g[t - 1] * f <=> G[t][i] = G[t][i] * F[i]
	}
	int res = 0;   // 原代码的 g[t][d]，第 t 次变换后，d 的值
	for (int k = 1; d * k < V; k++) {
		res += mu[k] * G[d * k];
	}
	if (res > 0) {
		cout << (t + n - 1) << endl;
		return;
	}
}
```

完整代码：

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr int N = 1e4;
vector<int> prime;
int minp[N];   // 最小素因子
int mu[N];     // 莫比乌斯函数

void solve() {
    int n;
    cin >> n;

    vector<int> a(n);
    int d = 0;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        d = gcd(d, a[i]);
    }

    int cnt = count(a.begin(), a.end(), d);
    if (cnt) {
        cout << (n - cnt) << endl;
        return;
    }

    const int V = *max_element(a.begin(), a.end()) + 1;

    vector<int> f(V);       // f[i]: 初始数组中数字 i 的出现次数
    for (auto x : a) {
        f[x] = 1;
    }

    vector<int> F(V);   // f 的变换域表示，原代码的 sumf
    for (int i = 1; i < V; i++) {
        for (int j = i; j < V; j += i) {
            F[i] += f[j];
        }
    }
    auto G = F;  // g[0] 的变换域表示，原代码的 sumg

    for (int t = 1; ; t++) {
        for (int i = 1; i < V; i++) {
            G[i] *= F[i];  // 做一次卷积 g[t] = g[t - 1] * f <=> G[t][i] = G[t][i] * F[i]
        }
        int res = 0;   // 原代码的 g[t][d]，第 t 次变换后，d 的值
        for (int k = 1; d * k < V; k++) {
            res += mu[k] * G[d * k];
        }
        if (res > 0) {
            cout << (t + n - 1) << endl;
            return;
        }
    }
}

int main() {
    cin.tie(nullptr)->sync_with_stdio(false);

    minp[1] = 1;
    mu[1] = 1;
    for (int i = 2; i < N; i++) {
        if (!minp[i]) {
            minp[i] = i;
            prime.push_back(i);
            mu[i] = -1;
        }
        for (auto p : prime) {
            if (i * p >= N) break;
            minp[i * p] = p;
            if (p == minp[i]) {
                mu[i * p] = 0;
                break;
            }
            mu[i * p] = -mu[i];
        }
    }

    for (int t = (cin >> t, t); t--; )
        solve();

    return 0;
}
```

分别将 Zeta - Möbius 变换应用于因数与倍数，得到两种相对偶的应用方式，即 Dirichlet 卷积和 GCD 卷积。

$$

    \xleftrightarrow
    [{\displaystyle x[n] = \sum_{d \mid n} \mu[d] \cdot X \Big[ \frac{n}{d} \Big]}]
    {\displaystyle X[n] = \displaystyle \sum_{d \mid n} x[d]}
    C[k] = A[k] \cdot B[k]
$$

$$
    c[k] = \sum_{\gcd(n, m) = k}^{} a[n] \cdot b[m]
    \xleftrightarrow
    [{\displaystyle x[n] = \sum_{d = 1}^ {\infty} \mu[d] \cdot X[n d]}]
    {\displaystyle X[n] = \sum_{d = 1}^ {\infty} x[n d]}

$$
其中 $d \mid n$ 表示 $d$ 是 $n$ 的约数，莫比乌斯函数 $\mu[n] = \begin{cases} 1, & n = 1 \\ 0, & \exists d > 1, d^{2} \mid n \\ (-1)^{\omega(n)}, & \text{otherwise}\end{cases}$ 可以用欧拉筛线性预处理。

## Möbius 变换在组合计数中的应用——二项式反演

*前置知识：[[组合计数]]*

### 二项式反演

二项式反演用于解决某个物品恰好若干个这类计数问题，其数学表达式是 Zeta - Möbius 在子集格 (Subset Lattice) 上的一个特例，其中函数的值只依赖于集合的大小。
$$
\begin{array}{clcl}
    & \text{正演} & & \text{反演} \\
    \hline
    \text{基本形式}
    & \displaystyle X[n] = \sum_{m = 0}^{n}(-1)^{m} \dbinom{n}{m} x[m]
    & \iff
    & \displaystyle x[n] = \sum_{m = 0}^{n}(-1)^{m} \dbinom{n}{m} X[m]      \\
    \text{至多与恰好的转换}
    & \displaystyle X[n] = \sum_{m = 0}^{n} \dbinom{n}{m} x[m]
    & \iff
    & \displaystyle x[n] = \sum_{m = 0}^{n}(-1)^{n - m} \dbinom{n}{m} X[m]  \\
    \text{转置式}
    & \displaystyle X[n] = \sum_{m = n}^{\infty}(-1)^{m} \dbinom{m}{n} x[m]
    & \iff
    & \displaystyle x[n] = \sum_{m = n}^{\infty}(-1)^{m} \dbinom{m}{n} X[m]  \\
    \text{至少与恰好的转换}
    & \displaystyle X[n] = \sum_{m = n}^{\infty} \dbinom{m}{n} x[m]
    & \iff
    & \displaystyle x[n] = \sum_{m = n}^{\infty}(-1)^{m - n} \dbinom{m}{n} X[m]  \\
\end{array}
$$

#### 错排公式

> 证明 [[组合计数#Derangement|Derangement]] $\displaystyle d[n] = n! \sum_{k = 0}^{n} \frac{(-1)^k}{k!}$。

设 $D[n]$ 表示至多有 $n$ 个位置错开，这就是 $n$ 元排列数，$D[n] = n!$。

$d[n]$ 表示恰好有 $n$ 个位置错开，套用至多与恰好的转换，
$$
\begin{aligned}
d[n] 
&= \sum_{m = 0}^{n}(-1)^{n - m} \dbinom{n}{m} D[m]
\\
&= \sum_{m = 0}^{n}(-1)^{n - m} \dbinom{n}{m} m!
\\
&= \sum_{m = 0}^{n}(-1)^{n - m} \dfrac{n!}{(n-m)!}
\\
&= n! \sum_{k = 0}^{n} \frac{(-1)^k}{k!}
\end{aligned}
$$
#### [BZOJ2839 集合计数](https://www.luogu.com.cn/problem/P10596)

> 给定 $n \leqslant N \leqslant 10^{6}$，从 $N$ 元集的所有 $2^N$ 个子集中取出若干集合，使得它们的交的元素个数为 $n$，求取法的方案数 $x[n]$，答案模 $\text{mod}=10^9+7$。

设交的元素个数至少为 $n$ 的取法方案数 $X[n]=\dbinom{N}{n}\big(2^{2^{N-n}}-1\big)$。

套用至少与恰好的转换，
$$
\begin{aligned}
x[n] 
&= \sum_{m = n}^{N} (-1)^{m - n} \dbinom{m}{n} X[m]
\\
&= \sum_{m = n}^{N} (-1)^{m - n} \dbinom{m}{n} \dbinom{N}{m}\big(2^{2^{N-m}}-1\big)
\end{aligned}
$$
直接 $\mathcal{O}(N)$ 计算即可，注意指数快速幂的模数是 $\text{mod}-1$。

```cpp
using Z = mull<u32, mod>;
using Z1 = mull<u32, mod - 1>;
Z res = 0;
for (int m = n; m <= N; m++) {
    res += ((m - n & 1) ? -1 : 1) 
          * binom(m, n) * binom(N, m) 
          * (qpow(Z(2), qpow(Z1(2), N - m).val()) - 1);
}
cout << res << endl;
```


### NTT 加速二项卷积 (Binomial Convolution)

组合数的分子分母有天然的指标之和为定值性质，可以利用多项式乘法的快速算法（如 FNTT）加速二项式变换。我们举一个题目为例。

#### [2025 清华预选赛 L](https://tsinghua2025.contest.codeforces.com/group/gtDllGnZc0/contest/618814/problem/L)

给定长为 $N$ 的数组 $A$ 和长为 $M$ 的数组 $B$，求
$$
S = \sum_{n = 1}^{M} \sum_{m = n+1}^{M} \sum_{k = 1}^{N} \dbinom{A_{k}}{B_{n}} \dbinom{A_{k} - B_{n}}{B_{m}} \bmod 998244353
$$
制約：$1 \leqslant N,M,A_{n},B_{n} \leqslant 2 \times 10^{5}$。

将无序对 $(n, m)$ 转化为有序对 $(n, m)$，设 
$$
\begin{aligned}
S_{0} &= \sum_{n = 1}^{M} \sum_{k = 1}^{N} \dbinom{A_{k}}{B_{n}} \dbinom{A_{k} - B_{n}}{B_{m}}
\\
S_{1} &= \sum_{n = 1}^{M} \sum_{m = 1}^{M} \sum_{k = 1}^{N} \dbinom{A_{k}}{B_{n}} \dbinom{A_{k} - B_{n}}{B_{m}}
\end{aligned}
$$
则答案为
$$
S = \frac{1}{2}(S_{1} - S_{0})
$$

先求 $S_{1}$，设值域为 $V$，把 $A,B$ 数组都塞进桶里，设
$$
A(x) = \sum_{n=1}^{N} x^{A_{n}} = \sum_{n=0}^{V - 1} a_{n} x^{n}, \quad
B(x) = \sum_{n=1}^{M} x^{B_{n}} = \sum_{n=0}^{V - 1} b_{n} x^{n}
$$
所求立即化为
$$
S_{1} = \sum_{k=0}^{V - 1} \sum_{n=0}^{V - 1} \sum_{m=0}^{V - 1} \dbinom{k}{n} \dbinom{k - n}{m} a_{k}b_{n}b_{m}
$$
为规范化组合数，做指标代换 $m \coloneqq m - n$，则
$$
\begin{aligned}
S_{1} &= \sum_{k=0}^{V - 1} \sum_{n=0}^{V - 1} \sum_{m=0}^{V - 1} \dbinom{k}{n} \dbinom{k - n}{m - n} a_{k}b_{n}b_{m-n}
\\
 &= \sum_{k=0}^{V - 1} \sum_{n=0}^{V - 1} \sum_{m=0}^{V - 1} \dbinom{k}{m} \dbinom{m}{n} a_{k}b_{n}b_{m-n}
\end{aligned}
$$
设
$$
E_{k} = \sum_{m=0}^{V - 1} \sum_{n=0}^{V - 1} \dbinom{k}{m} \dbinom{m}{n} b_{n}b_{m-n}
$$
再设
$$
F_{m} = \sum_{n=0}^{V - 1} \dbinom{m}{n} b_{n}b_{m-n}
$$
于是
$$
\begin{cases}
\displaystyle S_{1} = \sum_{k=0}^{V - 1} a_{k} E_{k} \\
\displaystyle E_{k} = \sum_{m=0}^{k} \dbinom{k}{m} F_{m} \\
\displaystyle F_{m} = \sum_{n=0}^{m} \dbinom{m}{n} b_{n}b_{m-n}
\end{cases}
$$

再求 $S_{0}$，用类似的方法得到
$$
F_{m} = \begin{cases}
\dbinom{m}{m/2} b_{m/2}, & 2 \mid m \\
0, & 2 \nmid m
\end{cases}
$$

对于 $S$，修正为
$$
\begin{cases}
\displaystyle S_{1} = \sum_{k=0}^{V - 1} a_{k} E_{k} \\
\displaystyle E_{k} = \sum_{m=0}^{k} \dbinom{k}{m} F_{m} \\
\displaystyle F_{m} = \dfrac{1}{2} \Bigg[\sum_{n=0}^{m} \dbinom{m}{n} b_{n}b_{m-n} - [2\mid m]\dbinom{m}{m/2} b_{m/2} \Bigg]
\end{cases}
$$
这就是最终答案。$F$ 序列的第一部分是 $b$ 自身的二项卷积，$E$ 是 $F$ 的二项变换，这都可以用 FNTT 在 $\mathcal{O}(V\log V)$ 的时间内求出。总复杂度 $\mathcal{O}(N + V\log V)$，$V = 2^{18}$。

```cpp
constexpr int V = 1 << 18;
auto solve = [&] {
	int N, M;
	cin >> N >> M;
	vector<Z> a(V), b(V);
	for (int i = 0; i < N; i++) {
		int x;
		cin >> x;
		a[x] += 1;
	}
	for (int i = 0; i < M; i++) {
		int x;
		cin >> x;
		b[x] += 1;	
	}
	vector<Z> c(V), d(V);
	for (int i = 0; i < V; i++) {
		c[i] = b[i] * invfac[i];
		d[i] = invfac[i];
	}
	c = c * c;
	for (int i = 0; i < V; i++) {
		c[i] *= fac[i];
		if (i % 2 == 0) {
			c[i] -= binom(i, i / 2) * b[i / 2];
		}
		c[i] /= 2;
		c[i] *= invfac[i];
	}
	c = c * d;
	Z res = 0;
	for (int i = 0; i < V; i++) {
		res += a[i] * c[i] * fac[i];
	}
	cout << res << endl;        
};
```

一般地，
$$
\boxed{
\begin{aligned}
    c[n]
    = \sum_{m = 0}^{n} a[m] \cdot b[n - m]
    &\iff
    \lbrace c[n] \rbrace
    =
    \lbrace a[n] \rbrace
    \ast
    \lbrace b[n] \rbrace
    \\
    c[n]
    = \sum_{m = 0}^{n} \binom{n}{m} a[m] \cdot b[n - m]
    &\iff
    \bigg\lbrace \dfrac{c[n]}{n!} \bigg\rbrace
    =
    \bigg\lbrace \dfrac{a[n]}{n!} \bigg\rbrace
    \ast
    \bigg\lbrace \dfrac{b[n]}{n!} \bigg\rbrace
\end{aligned}
}
$$

本质上这是 EGF (Exponential Generating Function, 指数生成函数)，
$$
    c[n]
    = \sum_{m = 0}^{n} \binom{n}{m} a[n] \cdot b[n - m]
    \xleftrightarrow
    [{\displaystyle a_n = \frac{\mathrm d^n A(x)}{\mathrm dx^n}  \bigg|_{x=0}}]
    {\displaystyle A(x) = \sum_{n=0}^{\infty} \dfrac{a_{n}}{n!}x^{n}}
    C(x) = A(x) \cdot B(x)
$$

应用到二项式反演中，如对于 $\displaystyle x[n] = \sum_{m = 0}^{n}(-1)^{n - m}\dbinom{n}{m} X[m]$，
$$
    \dfrac{x[n]}{n!}
    = \sum_{m = 0}^{n}\frac{(-1)^{n - m}}{(n - m)!}\dfrac{X[m]}{m!}
    \iff
    \bigg\lbrace \dfrac{x[n]}{n!} \bigg\rbrace
    =
    \bigg\lbrace \dfrac{(-1)^{n}}{n!} \bigg\rbrace
    \ast
    \bigg\lbrace \dfrac{X[n]}{n!} \bigg\rbrace
$$
这样给定序列 $X$，就能在 $\mathcal{O}(N\log N)$ 的时间内求得 $x$ 序列。

> Bingo 游戏，$N$ 个人每人要抢 $K$ 个数，主持人按随机顺序依次报数，报到每个数 $[1,10^{9}] \cap \mathbb{Z}$ 的概率相同。已知如果有多名选手要抢某个数字，那么编号小的选手总是优先抢到。问每个人成为最后一名（其他人都抢完了但自己还没抢完）的概率。

### [The 2024 ICPC Asia Nanjing Regional Contest I. Bingo](https://codeforces.com/gym/105484/problem/I)

> 给定一个长度为 $NM$ 的排列 $A$，将其打乱之后按顺序填入 $N \times M$ 的网格中。定义 Bingo 数为最小的整数 $K$，满足存在至少一行或者一列，其中所有的数都 $\leqslant  K$。要求出所有 $(NM)!$ 种打乱方式的 Bingo 整数之和，对 998244353 取模。$NM \leqslant 200000$。

---

#### Part 1 - Min-Max 反演

先考虑对于某一种确定的填数方法，Bingo 数是什么。

「所有的数都 $\leqslant K$」表明这一行（列）的最大值 $\leqslant K$；存在至少一行或者一列，且要 $K$ 最小，则网格 Bingo 数为所有行列的最大值的最小值。更具体地，对于每一行（列），设 $x_{i}$ 为该行（列）的最大值，并设 $S$ 为所有行（列）的 $x_{i}$ 的集合，则 Bingo 数为 $\min(S)$。

最大值的最小值不好处理，考虑 **Min-Max 反演**（Min-Max 容斥），转化为最大值的最大值。


> **【什么是 Min-Max 反演】**
> 
> 对于一个集合 $S$，其最小值（即全部元素的最小值，记作 $\min(S)$）与最大值可以由下式求得：
> $$
> \boxed{
> \begin{aligned}
> \displaystyle \min(S) = \sum_{\varnothing \neq T \subset S}^{} (-1)^{|T|-1} \max(T), \\
> \displaystyle \max(S) = \sum_{\varnothing \neq T \subset S}^{} (-1)^{|T|-1} \min(T).
> \end{aligned}
> }
> $$
> 
> 集合大小为 2 时，这是我们熟知的 $\max(a, b) + \min(a, b) = a + b$。
> 
> 回忆 **集合的容斥原理 (Principle of Inclusion - Exclusion, PIE)**，对于集合 $e_{1},e_{2},\dots,e_{n}$，设 $A=\lbrace e_{1},e_{2},\dots,e_{n} \rbrace$，那么 $\displaystyle \Bigg| \bigcup_{e \in A} e \Bigg| = \sum_{\varnothing \neq B \subseteq A} (-1)^{|B| - 1} \Bigg| \bigcap_{e \in B} e \Bigg|$。Min-Max 反演是将容斥原理应用于数的大小得到的，即，将取最大值视为并集，取最小值视为交集，将最值计算转化为对子集的组合求和，Min-Max 反演便化为容斥原理。容斥原理本身就是 Zeta - Möbius 的一个经典实例，因此 Min - Max 反演同样可以看作是 Zeta - Möbius 在子集格上的应用。
> 
> **【有什么用】**
> 
> Min-Max 反演很神奇，它表明极小与极大，存在与任意，小我与大我，共有和公有具有极强的对偶关系，可以相互转化。常用于 **整体的最值不好做，但可以将子集分类，每一类具有相同的性质，容易求得最值**。


回到本题，所求答案为所有 $(N M)!$ 种打乱方式的 $\min(S)$ 之和，这可以用 $\max(T)$ 表示。

$x_{i}$ 为该行（列）的最大值，$S$ 表示所有行（列）的 $x_{i}$ 的集合。$T$ 表示 $S$ 的子集，也即选择的若干行（列）的 $x_{i}$ 的集合，而 $x_{i}$ 表示一行（列）的最大值，所以 $T$ 表示选择的若干行（列）的所有元素的最大值。


---

#### Part 2 - 计数

对于确定的 $\max(T)$，即选出的最大值已经确定，下求有多少种填数方法。

设选择了 $n$ 行 $m$ 列，选择方案为 $\displaystyle \binom{N}{n} \binom{M}{m}$，且一共选择了 $c = M n + N m - n m$ 个元素，$T$ 的元素数量为 $|T|=n+m$。（*个人习惯用小写表示指标，大写表示常量，这样可以清楚地看出哪些是可以尝试优化的临时变量*）

不妨设序列从小到大排列，假设 $c$ 个元素的最大值为 $a_{k}$，即 $\max(T)=a_{k}$，则前 $k-1$ 个元素要选择 $c-1$ 个，总共这 $c$ 个元素任意填，方案数 $\displaystyle \binom{k-1}{c-1} c!(N M-c)!$。

于是答案为 
$$
\sum_{k=1}^{N M}\sum_{n=1}^{N}\sum_{m=1}^{M} (-1)^{n+m-1}
a_{k} \binom{N}{n} \binom{M}{m} \binom{k-1}{c-1} c!(N M-c)!
$$
表示选择了 $n$ 行 $m$ 列，且最大值为 $a_{k}$ 时的答案对 $n,m,k$ 求和。

暴力求需要三重循环枚举 $n,m,k$，复杂度是 $\mathcal{O}[(N M)^2]$。


---

#### Part 3 - 卷积优化

将式子转化为卷积快速求解。我们要求的是这一坨 
$$
\sum_{k=1}^{N M}\sum_{n=1}^{N}\sum_{m=1}^{M} (-1)^{n+m-1}
a_{k} \binom{N}{n} \binom{M}{m} \binom{k-1}{c-1} c! (N M-c)!
$$
交换求和号
$$
\sum_{n = 1}^{N} \sum_{m = 1}^{M} (-1)^{n+m-1} \binom{N}{n} \binom{M}{m} \cdot 
\sum_{k=1}^{N M} a_{k} \binom{k-1}{c-1} \cdot c! (N M-c)!
$$

考察
$$
\sum_{k=1}^{N M} a_{k} \binom{k-1}{c-1} \cdot c! (N M-c)!
$$
对于固定的 $c$，把 $k$ 优化掉，
$$
\begin{aligned}
&= \sum_{k=1}^{N M} a_{k} \cdot \frac{(k-1)!}{(c-1)!(k-c)!} \cdot c! (N M-c)!
\\ 
&= \sum_{k=1}^{N M} \frac{a_{k} (k-1)!}{(k-c)!} \cdot c (N M-c)!
\\ 
&= c (N M-c)! \cdot \sum_{k=1}^{N M} \frac{a_{k} (k-1)!}{(k-c)!}
\end{aligned}
$$

进一步考察
$$
F[c] = \sum_{k=1}^{N M} \frac{a_{k} (k-1)!}{(k-c)!}
$$
设 $f[n] = a_{n} (n-1)!$，$g[n] = \dfrac{1}{(N M - n)!}$，做卷积 $h = f \ast g$，得到
$$
h[n] 
= \sum_{k = 0}^{n} f[k] \cdot g[n-k]
= \sum_{k = 0}^{n} \frac{a_{k} (k-1)!}{(N M - n + k)!}
$$
可见
$$
h[N M + c]
= \sum_{k=1}^{N M} \frac{a_{k} (k-1)!}{(k-c)!}
$$
就是我们需要的 $F$，即 $F[c] = h[N M + c]$。

---

总答案
$$
\sum_{n = 1}^{N} \sum_{m = 1}^{M} (-1)^{n+m-1} \binom{N}{n} \binom{M}{m} \cdot c(N M-c)!\cdot h[N M + c]
$$
其中 $c = M n + N m - n m$。

预处理阶乘和组合数，先求 $h$ 数组，再二重循环枚举 $n,m$，总时间复杂度 $\mathcal{O}(N M\log N M)$。

```cpp
#include <bits/stdc++.h>

using namespace std;
using ll = long long;
using uint = unsigned;
using ull = unsigned long long;
using ulll = unsigned __int128;

using Z = mull<uint, mod>;  // 取模类

// NTT 快速数论变换
constexpr u32 mod = 998244353;
constexpr Z pr = 3; // Primitive root
constexpr Z ipr = 332748118;  // 1 / pr
vector<Z> operator * (vector<Z> a, vector<Z> b) {  // Convolution
	assert(mod == 998244353);
    const int n = 2 << __lg(a.size() + b.size() - 1);
    a.resize(n);
    b.resize(n);
    vector<int> rev(n);
    for (int i = 0; i < n; i++) {
        rev[i] = (rev[i >> 1] >> 1) | ((i & 1) * (n >> 1));
    }
    auto NTT = [&](vector<Z>& a, Z o = pr) {
        for (int i = 0; i < n; i++) {
            if (i < rev[i]) swap(a[i], a[rev[i]]);
        }
        for (int mid = 1; mid < n; mid <<= 1) {
            Z w0 = qpow(o, (mod - 1) / (mid << 1));
            for (int i = 0; i < n; i += mid << 1) {
                for (auto [w, j] = pair(Z(1), 0); j < mid; j++, w *= w0) {
                    Z& x = a[i + j];
                    Z& y = a[i + j + mid];
                    tie(x, y) = pair(x + w * y, x - w * y);
                }
            }
        }
    };
    auto INTT = [&](vector<Z>& a) {
        NTT(a, ipr);
        Z inv = 1 / Z(n);
        for (int i = 0; i < n; i++) {
            a[i] *= inv;
        }
    };
    NTT(a);
    NTT(b);
    for (int i = 0; i < n; i++) {
        a[i] *= b[i];
    }
    INTT(a);
    return a;  
};
// NTT 快速数论变换 end

Z fac[N], invfac[N], inv[N];
Z binom(int n, int m) {
    if (n < m || m < 0) return Z(0);
    return fac[n] * invfac[m] * invfac[n - m];
}

int main() {
    fac[0] = 1;
    for (int i = 1; i < N; i++) {
        fac[i] = fac[i - 1] * i;
    }
    invfac[N - 1] = 1 / fac[N - 1];
    for (int i = N - 1; i; i--) {
        invfac[i - 1] = invfac[i] * i;
        inv[i] = invfac[i] * fac[i - 1];
    }
    
	int J;
	cin >> J;

	while (J--) {
        int N, M;
        cin >> N >> M;

        vector<int> a(N * M + 1);
        for (int i = 1; i <= N * M; i++) {
            cin >> a[i];
        }
        sort(a.begin(), a.end());

        vector<Z> f(N * M + 1);
        vector<Z> g(N * M + 1);
        for (int i = 1; i <= N * M; i++) {
            f[i] = a[i] * fac[i - 1];
        }
        for (int i = 0; i <= N * M; i++) {
            g[i] = invfac[N * M - i];
        }
        auto h = f * g;

        Z res = 0;
        for (int n = 0; n <= N; n++) {
            for (int m = 0; m <= M; m++) {
                int c = M * n + N * m - n * m;
                res += (n + m & 1 ? 1 : -1) 
                      * binom(N, n) * binom(M, m) 
                      * c * fac[N * M - c] * h[N * M + c];
            }
        }
        cout << res << endl;
    }
    
	return 0;
}
```

#### Part 4 - Min-Max 反演的期望形式

> **【Min-Max 反演的期望形式】**
>
> 设 $\mathbb{E}[\min(S)$] 表示从 $S$ 中选出若干元素，即每个元素 $x_{i}\in S$ 都有一定概率选到时，$\min(S)$ 的期望，那么
> $$
> \boxed{
> \begin{aligned}
> \mathbb{E}[\min(S)] = \sum_{\varnothing \neq T \subset S}^{} (-1)^{|T|-1} \mathbb{E}[\max(T)], \\
> \mathbb{E}[\max(S)] = \sum_{\varnothing \neq T \subset S}^{} (-1)^{|T|-1} \mathbb{E}[\min(T)].
> \end{aligned}
> }
> $$
> $\min(S)$ 一般表示最小、有一次或第一个，$\max(S)$ 表示最大、全部或最后一个。

第二题要求最大值 $\leqslant K$，我们设 $x_{i}$ 为该行（列）的最大值。本题要求全部被标记，那么对于每一行（列），定义 $x_{i}$ 表示这一行（列）全部被标记的期望时间，$S$ 为所有 $x_{i}$ 的集合，那么所求为有一行（列）的 $x_{i}$ 发生的期望时间，也即 $\min(S)$。如果一个位置有标记，那这一行（列）的 $x_{i}$ 一定是正无穷，不会对 $\min(S)$ 有贡献，因此可以直接剔除，只考虑剩下的 $\min(S)$。

刚才我们说，Min-Max 反演常用于整体的最值不好做，但可以将子集分类，每一类具有相同的性质，容易求得最值的情形。

- 整体的最值不好做吗？$x_{i}$ 表示全部被标记，是 $\max$，要求 $\max$ 的 $\min$，不好求，但 $\max$ 的 $\max$ 好求，因此把 $\min(S)$ 用 Min-Max 反演转为子集的 $\max(T)$。思考 $\max(T)$ 的含义：$\max(T)$ 表示 $T$ 中所有行和列的 $x_{i}$ 发生的期望时间，而 $x_{i}$ 表示这一行（列）全部被标记，所以 $\max(T)$ 表示的是 $T$ 中所有格子都被标记的期望时间。

- 如何分类？再看公式的形式：$\displaystyle \mathbb{E}[\min(S)] = \sum_{\varnothing \neq T \subset S}^{} (-1)^{|T|-1} \mathbb{E}[\max(T)]$，由于概率均等，这里 $T$ 只关心集合大小，我们就按集合大小分类，转为求解全部 $NM$ 个数字报出这 $n$ 行 $m$ 列所有 $c = M n + N m - n m$ 个数字的期望时间，这等于 $\displaystyle \sum_{n=1}^{c} \dfrac{NM}{n}$。然后枚举 $n, m$ 求解。

```cpp
void solve() {
	int N, M, K;
	cin >> N >> M >> K;
	
	vector<int> visX(N), visY(M);
	vector<Z> pre(N * M + 1);
	for (int i = 1; i <= N * M; i++) {
		pre[i] = pre[i - 1] + inv[i] * N * M;
	}

	while (K--) {
		int n, m;
		cin >> n >> m;
		n--, m--;
		visX[n] = true;
		visY[m] = true;
	}

	int cntX = count(visX.begin(), visX.end(), 0);
	int cntY = count(visY.begin(), visY.end(), 0);

	Z res = 0;
	for (int n = 0; n <= cntX; n++) {
		for (int m = 0; m <= cntY; m++) {
			int c = M * n + N * m - n * m;
			res += (n + m & 1 ? 1 : -1) 
			      * binom(cntX, n) * binom(cntY, m) 
			      * pre[c];
		}
	}

}
```

$$

        \\

        \\
        \min(S) 
        &= \sum_{\varnothing \neq T \subset S}^{} (-1)^{|T| - 1} \max(T)
        \\
        \max(S) 
        &= \sum_{\varnothing \neq T \subset S}^{} (-1)^{|T| - 1} \min(T)
        \\

## 离散傅立叶变换 DFT & 线性卷积

卷积是一种数学运算，它将两个序列混合起来，生成第三个序列。最常见的是卷积和。

长度为 $n+1$ 的序列 $\lbrace  f_{i} \rbrace_{0 \leqslant i \leqslant n}$ 与长度为 $m+1$ 的序列 $\lbrace  g_{i} \rbrace_{0 \leqslant i \leqslant m}$ 做 **卷积和**（或简称 **卷积**），得到的结果是长度为 $n+m+1$ 的序列 $\lbrace a_{i} \rbrace_{0 \leqslant i \leqslant n+m}$，记作 $a=f \ast g$，其中 $\displaystyle c[k] = \sum_{n=0}^{k} a[n] \cdot b[n - k]$，或简写为 $\displaystyle c[k] = \sum_{n+m=k}^{} a[n] \cdot b[m]$。卷积满足交换律和结合律。它的核心特征是 **下标之和为定值**。

初中所学的 **多项式相乘** 是卷积，两个多项式 $f(x)=f_{n}x^{n}+f_{n-1}x^{n-1}+\dots+ f_{0}$ 与 $g(x)=g_{m}x^{m}+g_{m-1}x^{m-1}+\dots+ g_{0}$ 相乘，得到的新多项式 $a(x)=a_{m+n}x^{m+n}+a_{m+n-1}x^{m+n-1}+\dots+ a_{0}$ 中，$\displaystyle a_{k}=\sum_{i=0}^{k}f_{i}g_{k-i}$ 就是卷积结果。我们熟知的 $(a+b)^{2}=a^{2}+2ab+b^{2}$ 其实是 $\lbrace 1,1 \rbrace \ast \lbrace 1,1 \rbrace=\lbrace 1,2,1 \rbrace$。

在多项式中取 $x=10$，就得到了小学所学的 **数字乘法**，$11\times 11=121$。


$$
    c[k] = \sum_{n+m=k}^{} a[n] \cdot b[m]
    \xleftrightarrow
    [{\displaystyle x[n] = \sum_{n=0}^{N-1} \mathrm{e}^{\frac{2 \pi \mathrm i}{N} kn} X[k] \iff \boldsymbol{x} = \boldsymbol{W}^{-1} \boldsymbol{X}}]
    {\displaystyle X[k] = \sum_{n=0}^{N-1} \mathrm{e}^{-\frac{2 \pi \mathrm i}{N} kn} x[n] \iff \boldsymbol{X} = \boldsymbol{W} \boldsymbol{x}}
    C[k] = A[k] \cdot B[k]
$$

记 $\omega_{N}^{k} = \mathrm{e}^{-\frac{2 \pi \mathrm i k}{N}}$，那么
$$
\boldsymbol{W}
= \begin{bmatrix}
1 & 1 & 1 & \cdots & 1 \\
1 & \omega_N^1 & \omega_N^2 & \cdots & \omega_N^{N-1} \\
1 & \omega_N^2 & \omega_N^4 & \cdots & \omega_N^{2(N-1)} \\
\vdots & \vdots & \vdots & \ddots & \vdots \\
1 & \omega_N^{N-1} & \omega_N^{2(N-1)} & \cdots & \omega_N^{(N-1)(N-1)}
\end{bmatrix}
$$
这是一个 Vandermonde 矩阵，也是一个经过缩放的酉矩阵 (unitary matrix)，满足正交性即
$$
    \boldsymbol{W} \boldsymbol{W}^{\mathrm H} = N \boldsymbol{I}_N
    \iff
    \boldsymbol{W}^{-1} = \frac{1}{N}\boldsymbol{W}^{\mathrm H}
$$
式中 $\boldsymbol{W}^{\mathrm H}$ 是 $\boldsymbol{W}$ 的共轭转置 (Hermitian transpose)。

**快速傅里叶变换 (Fast Fourier Transform, FFT)** 支持在 $\mathcal{O}(n\log n)$ 的时间内计算一次正/反变换；如果是整数序列且模数是比较特殊的 998244353，还可以用 **快速数论变换 (Number Theoretic Transforms, NTT)**，减小精度损失。

如果看到 $\boxed{\displaystyle a_{k}=\sum_{i+j=k}^{}f_{i}g_{j}}$ 这种式子，**两者相乘再求和，且指标之和为定值**，暴力求 $a$ 序列是 $\mathcal{O}(n^{2})$ 的，就可以考虑卷积优化，即 $a=f\ast g$。如果是 $\displaystyle a_{\ell}=\sum_{i+j+k=\ell}^{}f_{i}g_{j}h_{k}$，可以写成 $a=f \ast g \ast h$，以此类推。

### 多项式乘法

设 $N - 1$ 次多项式 $H(z) = h_{0} + h_{1}z + h_{2}z^{2} + \dots + h_{N-1}z^{N-1}$ 的系数向量 $\boldsymbol{h} = [h_{0}, h_{1}, \dots, h_{N-1}]$，对应的 $N \times N$ 循环矩阵 $\boldsymbol{C}$ 为
$$
\boldsymbol{C} = 
\begin{bmatrix}
h_{0} & h_{N-1} & h_{N-2} & \cdots & h_{1} \\
h_{1} & h_{0} & h_{N-1} & \cdots & h_{2} \\
\vdots & \vdots & \vdots & \ddots & \vdots \\
h_{N-1} & h_{N-2} & h_{N-3} & \cdots & h_{0}
\end{bmatrix}
$$
这是一个 **野羊矩阵**，它是 Toeplitz 矩阵的一个特例。

野羊矩阵 $\boldsymbol{C}$ 可以被 DFT 系数矩阵 $\boldsymbol{W}$ 对角化
$$ \boldsymbol{C} = \boldsymbol{W}^{-1} \cdot \text{diag}(\boldsymbol{W} \boldsymbol{h}) \cdot \boldsymbol{W} $$

两个多项式 $H(z)$ 和 $X(z)$ 之积 $Y(z) = H(z) X(z)$ 的系数向量 $\boldsymbol{y}$ 是 $\boldsymbol{h}$ 和 $\boldsymbol{x}$ 的 **卷积和**，
$$
y[n] = \sum_{m = 0}^{n} h[m] \cdot x[n - m]
$$
用野羊矩阵描述为
$$
\boldsymbol{y} 
= \boldsymbol{C} \boldsymbol{x} 
= \boldsymbol{W}^{-1} \cdot \text{diag}(\boldsymbol{W} \boldsymbol{h}) \cdot \boldsymbol{W} \boldsymbol{x} 
$$
例如 $N = 2$ 时，
$$
\begin{bmatrix} y_{0} \\ y_{1} \\ y_{2} \end{bmatrix}
=
\begin{bmatrix}
h_{0} & 0 & h_{1} \\
h_{1} & h_{0} & 0 \\
0 & h_{1} & h_{0}
\end{bmatrix}
\begin{bmatrix} x_{0} \\ x_{1} \\ 0 \end{bmatrix}
=
\begin{bmatrix} h_{0} x_{0} \\ h_{1} x_{0} + h_{0} x_{1} \\ h_{1} x_{1} \end{bmatrix}
$$
以快速傅里叶变换为基石的多项式算法赋予了算法竞赛选手直接操纵多项式的能力，操纵多项式是 OI 数学中极其重要的内容。

### 矩阵快速幂

设序列 $\lbrace a_{n} \rbrace$ 的递推公式为 $a_{n}= p \cdot a_{n - 1} + q \cdot a_{n - 2}$，给定 $p, q, a_{0}, a_{1}, N, M$，求 $a_{N} \bmod M$。

### 关于 $\pi$ 的无穷级数

**莱布尼茨级数 (Leibniz Formula)**
$$\frac{\pi}{4} = 1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \frac{1}{9} - \cdots = \sum_{n=0}^{\infty} \frac{(-1)^n}{2n+1}$$

**巴塞尔问题与黎曼 Zeta 函数 (Basel Problem and Riemann Zeta Function)**
$$\frac{\pi^2}{6} = 1 + \frac{1}{2^2} + \frac{1}{3^2} + \frac{1}{4^2} + \cdots = \sum_{n=1}^{\infty} \frac{1}{n^2}$$

这个结果是黎曼 Zeta 函数 $\displaystyle \zeta(s) = \sum_{n=1}^{\infty} \frac{1}{n^s}$ 在 $s=2$ 时的特例，即 $\zeta(2) = \frac{\pi^2}{6}$。欧拉还进一步发现了 Zeta 函数在所有正偶数整数点的值都与 $\pi$ 的偶数次幂相关，如
* $\displaystyle \zeta(4) = \sum_{n=1}^{\infty} \frac{1}{n^4} = \frac{\pi^4}{90}$
* $\displaystyle \zeta(6) = \sum_{n=1}^{\infty} \frac{1}{n^6} = \frac{\pi^6}{945}$


**尼拉坎塔级数 (Nilakantha's Series)**
$$\pi = 3 + \frac{4}{2 \times 3 \times 4} - \frac{4}{4 \times 5 \times 6} + \frac{4}{6 \times 7 \times 8} - \cdots = 3 + \sum_{n=1}^{\infty} \frac{4(-1)^{n+1}}{(2n)(2n+1)(2n+2)}$$

**马德哈瓦级数 (Madhava's Series)**
$$\frac{\pi}{\sqrt{12}} = 1 - \frac{1}{3 \cdot 3} + \frac{1}{5 \cdot 3^2} - \frac{1}{7 \cdot 3^3} + \cdots = \sum_{n=0}^{\infty} \frac{(-1)^n}{(2n+1)3^n}$$

这个级数是 $\displaystyle \arctan x = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n+1}}{2n+1}$ 在 $x = \dfrac{1}{\sqrt{3}}$ 时的特例，因为 $\arctan\dfrac{1}{\sqrt{3}} = \dfrac{\pi}{6}$。

## 线性基

**GF(2) 域** 是一个包含两个元素 $0$ 和 $1$ 的有限域，其元素 $a$ 和 $b$ 的加法 $a + b$ 定义为逻辑异或 (XOR, $\oplus$)，乘法 $ab$ 定义为逻辑与 (AND, $\&$)，即
$$
\begin{array}{cc}
    0 + 0 = 0 & 0 \times 0 = 0 \\
    0 + 1 = 1 & 0 \times 1 = 0 \\
    1 + 0 = 1 & 1 \times 0 = 0 \\
    \boldsymbol{\color{blue}1 + 1 = 0} & 1 \times 1 = 1
\end{array}
$$
$a$ 和 $b$ 的逻辑或 (OR, $\mid$) 可以表示为
$$
    a + b + a b
$$
在 $\operatorname{GF}(2)$ 中，一组向量的 **线性组合 (linear combination)**，实际上就是从这组向量中选取一个子集，然后将它们全部异或起来。

将一个 $B$ 位的无符号整数 (`unsigned int`) 看作是 $\operatorname{GF}(2)$ 上一个 $B$ 维向量空间中的向量。对于一个给定无符号整数集合，考虑数集对应的向量集合。

**线性基** 是一种数据结构，本质是这个集合的 **基 (Basis)**。原集合中的任何一个整数，都可以由这个基中的数通过异或表示出来。反之，由基中整数异或出的任何结果，也能被原集合中的整数异或表示。

简而言之，线性基是原集合的一个最简化的代表团，它能表示出与原集合完全相同的「异或空间」，这使得很多查询操作变得非常高效。

```cpp
constexpr unsigned B = 32;  // constexpr ull B = 64;
struct Basis {
    array<unsigned, B> h{};
    unsigned siz = 0;
    bool duplicate = 0;  // 是否有重复元素

    bool insert(unsigned x) {  // 每行只有一个 1
        for (int bit = B - 1; bit >= 0; bit--) {
            if (x >> bit & 1) {
                if (!h[bit]) {
                    for (int rua = bit - 1; rua >= 0; rua--) {
                        if (h[rua] && (x >> rua & 1)) {
                            x ^= h[rua];
                        }
                    }
                    for (int rua = bit + 1; rua < B; rua++) {
                        if (h[rua] >> bit & 1) {
                            h[rua] ^= x;
                        }
                    }
                    h[bit] = x;
                    siz++;
                    return true;
                }
                x ^= h[bit];
            }
        }
        duplicate = 1;
        return false;
    }

    bool count(unsigned x) { // 能否表示成x
        for (int bit = B - 1; bit >= 0; bit--) {
            if (x >> bit & 1) {
                if (h[bit]) {
                    x ^= h[bit];
                } else {
                    return false;
                }
            }
        }
        return true;
    }

    // 能表示的元素个数
    unsigned size() {
        return 1ull << siz;
    }

    // 利用x能表示的最大值
    unsigned queryMax(unsigned x = 0) {
        for (int bit = B - 1; ~bit; bit--) {
            x = max(x, x ^ h[bit]);
        }
        return x;
    }

    // 利用x能表示的最小值
    unsigned queryMin(unsigned x) {
        for (int bit = B - 1; ~bit; bit--) {
            x = min(x, x ^ h[bit]);
        }
        return x;
    }

    // 仅用线性基内元素能表示的最小值
    unsigned queryMin() {
        if (duplicate) return 0;
        for (int bit = 0; bit < B; bit++) {
            if (h[bit]) return h[bit];
        }
        return 0;
    }

    // 高斯消元
    void GaussJordanElimination() {
        for (int rua = B - 1; rua >= 0; rua--) {
            for (int bit = rua - 1; bit >= 0; bit--) {
                if (h[rua] >> bit & 1) {
                    h[rua] ^= h[bit];
                }
            }
        }
    }

    // 仅用线性基内元素能表示的第 k 小 其中第 0 小为最小
    unsigned queryKthmin(unsigned x) {
        if (!duplicate) x++;
        if (x >= size()) return -1;
        unsigned res = 0;
        int cnt = 0;
        GaussJordanElimination();
        for (int bit = 0; bit < B; bit++) {
            if (h[bit] == 0) continue;
            if (x >> cnt & 1) res ^= h[bit];
            cnt++;
        }
        return res;
    }

    // 仅用线性基内元素能表示的第 k 大
    unsigned queryKthmax(unsigned x) {
        if (x >= size()) return -1;
        return queryKthmin(size() - x);
    }
};
```

```cpp
vector<ull> dis(n);
vector<int> vis(n);
auto dfs = [&](this auto&& dfs, int u) -> void {
```

### 2024 ICPC 网络赛 (I) C. Permutation Counting 4

> 给定 $n$ 个区间 **$[l_i, r_i]$**，求满足 $l_i \leqslant p_i \leqslant r_i$ 的 **排列 (permutation)** **$p$** 的数量，输出 **模 2** 的结果。

构造一个 0-1 矩阵 $\boldsymbol{A} = (a_{ij})_{n\times n}$，
$$
a_{i,j} = 
\begin{cases} 1, & l_i \leqslant j \leqslant r_i \\
0, & \text{otherwise}  \\
\end{cases}
$$
题目所求的排列数严格等于矩阵 $\boldsymbol{A}$ 的 **积和式 (permanent)**，其定义与 **行列式 (determinant)** 非常相似，但没有符号项，即
$$
\begin{aligned}
\det(\boldsymbol{A}) &= \sum_{\sigma \in S_n} \operatorname{sgn}(\sigma) \prod_{i=1}^{n} a_{i, \sigma(i)}
\\
\text{per}(\boldsymbol{A}) &= \sum_{\sigma \in S_n} \prod_{i=1}^{n} a_{i, \sigma(i)}
\end{aligned}
$$
式中
-   $S_n$ 是集合 $\{1, 2, ..., n\}$ 上所有 **置换** ($\sigma$) 的集合。
-   $\operatorname{sgn}(\sigma)$ 是 **置换** $\sigma$ **的符号**，定义为 $\operatorname{sgn}(\sigma) = (-1)^{N(\sigma)}$，其中 $N(\sigma)$ 为一个置换中 **逆序** 的总个数。

由于只需输出模 2 的结果，我们在 **有限域 GF(2)** 上解决问题。

排列符号 $\operatorname{sgn}(\sigma)$ 的值，无论是 $+1$ 还是 $-1$，在 GF(2) 上都等于 1。行列式定义中的 $\operatorname{sgn}(\sigma)$ 这一项失去了作用，两个公式变得完全相同，
$$
\det(\boldsymbol{A})  \equiv  \text{per}(\boldsymbol{A}) \pmod 2 
$$
题目所求的排列数模 2，等价于计算矩阵 $\boldsymbol{A}$ 在 GF(2) 上的行列式 $\det(\boldsymbol{A})$。

对矩阵 $\boldsymbol{A}$ 做初等列变换，用类似后缀差分的方法，将 $\boldsymbol{A}$ 中一串连续的 1，用差分化为两个离散的 1，得到矩阵 $\boldsymbol{B}$。矩阵 $\boldsymbol{B}$ 的第 $i$ 行 **仅在第 $l_i-1$ 列和第 $r_i$ 列为 1**。

形式化地，设
$$
\boldsymbol{B} = \boldsymbol{A} \cdot \boldsymbol{T}^{-1}
$$
其中 $\boldsymbol{T}$ 为 $n$ 阶 **下三角矩阵** 
$$
\boldsymbol{T} = \begin{bmatrix}
1 & 0 & 0 & \dots & 0 \\
1 & 1 & 0 & \dots & 0 \\
1 & 1 & 1 & \dots & 0 \\
\vdots & \vdots & \vdots & \ddots & \vdots \\
1 & 1 & 1 & \dots & 1
\end{bmatrix}
\quad
\boldsymbol{T}^{-1} = \begin{bmatrix}
1 & 0 & 0 & \dots & 0 \\
1 & 1 & 0 & \dots & 0 \\
0 & 1 & 1 & \dots & 0 \\
\vdots & \vdots & \ddots & \ddots & \vdots \\
0 & 0 & \dots & 1 & 1
\end{bmatrix}
$$
这里的矩阵 $\boldsymbol{A}$, $\boldsymbol{B}$, 和 $\boldsymbol{T}$ 的所有运算都在 GF(2) 上进行。

由于 $\det(\boldsymbol{T}) = 1$，
$$
\det(\boldsymbol{A}) = \det(\boldsymbol{B}) \cdot \det(\boldsymbol{T}) = \det(\boldsymbol{B})
$$
问题转化为计算这个新的 $\boldsymbol{B}$ 的行列式。

我们知道，$\det(\boldsymbol{B})$ 为 0 当且仅当其行向量线性相关，也就是存在若干行，它们的和为零向量。

这个新的 $\boldsymbol{B}$ 结构与一个图模型完美对应。图的**顶点**对应矩阵的**列**，**边**对应矩阵的**行**。如果矩阵第 $i$ 行在第 $u$ 列和第 $v$ 列有 `1`，我们就在顶点 $u$ 和 $v$ 之间画一条边 $e_i$。

我们将证明，**一组行向量线性相关** 与 **它们对应的边在图中构成环** 等价。

一方面，假设我们在图 $\boldsymbol{G}$ 中找到了一个环 (cycle)，并假设这个环由 $k$ 条边 **$\lbrace e_1, e_2, \dots, e_k \rbrace$** 构成。这些边对应于矩阵 $\boldsymbol{B}$ 中的 $k$ 个行向量 **$\lbrace \boldsymbol{R}_1, \boldsymbol{R}_2, \dots, \boldsymbol{R}_k \rbrace$**。

我们要证明这组行向量是**线性相关**的，就是要证明
$$
\boldsymbol{R}_1 + \boldsymbol{R}_2 + \dots + \boldsymbol{R}_k = \boldsymbol{0}
$$
只需要证明它的每一个分量都为 0。考察和向量的第 $j$ 个分量，要证明
$$
\boldsymbol{R}_{1,j} + \boldsymbol{R}_{2,j} + \dots + \boldsymbol{R}_{k,j}
$$
现在我们把这个式子和图联系起来：
* $\boldsymbol{R}_{i,j} = 1$ 意味着边 $e_i$ 连接到了顶点 $j$。
* 所以，上面的和式 $\boldsymbol{R}_{1,j} + \dots + \boldsymbol{R}_{k,j}$ 实际上是在**计算这个环里有多少条边连接到了顶点 j**。

根据**环**的定义：
* 如果顶点 $j$ **是**这个环上的一个顶点，那么**恰好有两条边**（属于这个环的边）与它相连。因此，在和式中会有两个 `1`，其余都是 `0`。其结果是 **$1 + 1 = 0$** (在 GF(2) 中)。
* 如果顶点 $j$ **不是**这个环上的顶点，那么**没有**环上的边与它相连。因此，和式中全都是 `0`。其结果是 **0**。

无论哪种情况，对于任意一个顶点 $j$，和向量的第 $j$ 个分量都为 **0**。因此，$\boldsymbol{R}_1 + \boldsymbol{R}_2 + \dots + \boldsymbol{R}_k$ 确实是零向量。

这便证明了，只要在图中能找到一个环，其对应的行向量集合一定是线性相关的。

另一方面，假设找到了一个最小的非空行向量集合 **$\lbrace \boldsymbol{R}_1, \boldsymbol{R}_2, \dots, \boldsymbol{R}_k \rbrace$**，它们是线性相关的，即满足
$$
\boldsymbol{R}_1 + \boldsymbol{R}_2 + \dots + \boldsymbol{R}_k = \boldsymbol{0}
$$
考察这个和向量的第 $j$ 个分量
$$
\boldsymbol{R}_{1,j} + \boldsymbol{R}_{2,j} + \dots + \boldsymbol{R}_{k,j} = 0
$$

它告诉我们，对于**任意一个顶点 $j$**，连接到它的边的数量必须是**偶数**。进而，在由边集 $\lbrace e_1, \dots, e_k \rbrace$ 和它们所连接的顶点构成的子图中，**每个顶点的度数 (degree) 都是偶数**。

根据图论的一个基本定理：**一个所有顶点的度数都为偶数的图，可以被分解成若干个互不相交的环的并集**。

因为我们假设我们找到的是一个**最小的**线性相关集，所以这个子图不可再分，它只能由**一个单独的环**构成。如果它由两个或多个不相交的环构成，那么任何一个环本身就构成了一个更小的线性相关集，与我们的“最小”假设矛盾。

这便证明了，任意一个最小线性相关行向量集合，都对应图中的一个简单环。

最终，这个问题就漂亮地转化了：计算 $\det(\boldsymbol{B})$ 是否为 0 $\iff$ 判断 $\boldsymbol{B}$ 的行向量是否线性相关 ⇔ 判断根据 $\boldsymbol{B}$ 构建的图 $\boldsymbol{G}$ 中是否存在环。

### [2115D / 2116F - Gellyfish and Forget-Me-Not](https://codeforces.com/contest/2115/problem/D)

先置 $a_{i}:=a_{i}+ b_{i},\mathrm{res}:=\mathrm {res}+ b_{i}$，这样相当于每个人可以选择要不要 $a_{i}$。考虑 $a$ 只有 01 怎么做：最后一个拿到 $a =1$ 的人有决定权，可以改成他想要的数。因此检查最后一个 $a =1$ 的位置，如果是 $c=1$，那么答案为 1，否则答案为 0。如果有多位，就要知道每一个二进制位的决定权在谁手上。倒序遍历（因为要找最后一个位置）$a$ 并插入线性基，设将 $a_{i}$ 插入线性基后的最高位为 $2^{d}$，那么 $d$ 的决定权就在 $c_{i}$ 手上。现在，从高到低遍历每个二进制位，这一位 $d$ 的决定权在谁手上，这个人就能把这一位变成他想要的数（ $c=1$ 则变成 1，否则变成 0）。

### [2025 CCPC 北京市赛暨小米杯全国邀请赛 H. 矩阵除法](https://codeforces.com/gym/105851/problem/I)

> 对于 $N \times M$ 的 01 矩阵 $A$ 和 $M \times P$ 的 01 矩阵 $B$，定义它们的乘积为一个 $N \times P$ 的 01 矩阵 $C$，$C_{i,j} = \bigoplus_{k=1}^{m} \left( A_{i,k} \& B_{k,j} \right)$。给出 $A,C$，找出一个 $B$，或报告不存在。数据范围：$N,M,P \leqslant 1000$。

在 GF(2) 上 $C=AB$。考虑求解 $B$ 的第 $j$ 列，$C_{:j}=AB_{:j}$，这是一个 $M$ 元一次方程，用高斯消元求解。将 $C_{:j}$ 拼起来以同时求解所有方程。复杂度 $\mathcal{O}\big(\frac{N^{2}(M+P)}{W}\big)$。

```cpp
for (int i = 0; i < n; i++) {

					}

					hc[bit] = c[i];
					return true;
				}
				a[i] ^= ha[bit];
				c[i] ^= hc[bit];
			}
		}
		return c[i].none();
	};
	if (!insert()) {
		cout << "No" << endl;
		return 0;
	}
}
```

### 前缀线性基

```cpp
constexpr int D = 20;
struct Basis {
    array<int, D> h{}, t{};

    Basis() {
        fill(t.begin(), t.end(), -1);
    }

    void insert(int x, int y = 1E9) {
        for (int bit = D - 1; ~bit; --bit) {
            if (x >> bit & 1) {
                if (y > t[bit]) {
                    swap(h[bit], x);
                    swap(t[bit], y);
                }
                x ^= h[bit];
            }
        }
    }

    bool query(int x, int y = 0) {
        for (int bit = D - 1; ~bit; --bit) {
            if ((x >> bit & 1) && t[bit] >= y) {
                x ^= h[bit];
            }
        }
        return x == 0;
    }

    // 能表示的最大值
    ll quemax(ll res = 0, int y = 0) {
        for (int bit = D - 1; ~bit; bit--) {
            if (t[bit] >= y) {
                res = max(res, res ^ h[bit]);
            }
        }
        return res;
    }
};
```

**例 2** 一棵 $n$ 个点的树，每个点有一个点权 $a_i$。$q$ 个询问，每次给出三个数 $x_i, y_i, k_i$，你需要回答是否能从 $x_i$ 到 $y_i$ 的简单路径中选出若干个点（可包含 $x_i, y_i$，可一个都不选），使得这些点的点权异或和为 $k_i$。([CF1902F. Trees and XOR Queries Again](https://codeforces.com/contest/1902/problem/F))

如果我们能把 $x \to y$ 路径上的所有点权插入到线性基，那么可以 $O(\log V)$ 查询。但是因为线性基合并只能 $O(\log^2 V)$，所以只能倍增做 $O((n + q) \log n \log^2 V)$，过不了。

考虑 $O(n \log V)$ 预处理出每个点到根的所有点权的线性基 $f_u$，那么对于一个询问，把 $f_x$ 和 $f_y$ 合并，再抠掉 $\text{lca}(x, y)$ 以上部分的点权，也就是只考虑深度 $\geqslant dep_{\text{lca}(x, y)}$ 的元素，这就是前缀线性基。时间复杂度 $O(n\log V + q \log^{2} V)$。

```cpp
int n;
cin >> n;

vector<int> val(n);
for (int u = 0; u < n; u++) {
    cin >> val[u];
}

TREE tree(n);
for (int i = 1; i < n; i++) {
    int u, v;
    cin >> u >> v;
    u--, v--;
    tree.add_edge(u, v);
}
tree.work(0);

vector<Basis> basis(n);
auto dfs = [&](auto&& self, int u) -> void {
    basis[u].insert(val[u], tree.dep[u]);
    for (auto v : tree.g[u]) {
        basis[v] = basis[u];
        self(self, v);
    }
};
dfs(dfs, 0);

int q;
cin >> q;
while (q--) {
    int u, v, k;
    cin >> u >> v >> k;
    u--, v--;
    int l = tree.lca(u, v);
    auto bas = basis[u];
    for (int i = 0; i < D; i++) {
        if (basis[v].t[i] >= tree.dep[l]) {
            bas.insert(basis[v].h[i]);
        }
    }
    cout << (bas.query(k, tree.dep[l]) ? "YES" : "NO") << endl;
}
```
