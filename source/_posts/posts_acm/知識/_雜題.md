## 二进制的小数点后

Alice 和 Bob 初始筹码为 A 和 B。奖金初始为 1。每一轮，筹码多的人拿走剩余奖金的一半，并付给对方等同于对方目前拥有的筹码。游戏无限进行，Alice 最终会拿到多少奖金？

$A' = (2 A) \bmod (A+B)$

$x' = 2x \bmod 1$

注意到第 $i$ 轮 A 的筹码更多，等价于答案二进制的小数点后第 $i$ 位是 1。


### [CF1852C](https://codeforces.com/contest/1852/problem/C)

给定 $\mathbb{Z} / K \mathbb{Z}$ 上的数组 $\lbrace A_{n} \rbrace_{n = 1}^{N}$，每次可选择子区间减一，问将数组清零的最小操作次数。$N \leqslant 10^{5}, K \leqslant 10^{9}$。

不妨设 $A_{0} = 0$。

转化到 $\mathbb{Z}$ 上，视为先做若干次 $+K$，再做子区间减一。

若仅考虑子区间减一，答案是
$$
\sum_{n = 1}^{N} \max\lbrace 0, A_{n} - A_{n - 1} \rbrace
$$

回到原题，分两种情形，
- 若 $A_{n} \leqslant A_{n - 1}$，不需要 $+K$。
- 若 $A_{n} > A_{n - 1}$，
    - 可以选择不 $+K$，给答案加上 $A_{n} - A_{n - 1}$；
    - 也可以选择一个子区间 $[x, n - 1]$ $+K$，其中 $A_{x} \leqslant A_{x-1}$，给答案加上 $A_{x} + K - A_{x - 1}$。

综合来看，
- 若 $A_{n} \leqslant A_{n - 1}$，对答案的贡献可能是 0，也可能是 $A_{n} + K - A_{n - 1}$。
- 若 $A_{n} > A_{n - 1}$，对答案的贡献可能是 $A_{n} - A_{n - 1}$。

用优先队列存储可能的答案，每次选最小的对答案做贡献。

```cpp
void solve() {
    int N, K;
    std::cin >> N >> K;
 
    std::vector<int> A(N + 1);
    for (int n = 1; n <= N; n++) {
        std::cin >> A[n];
        A[n] %= K;
    }
 
    std::priority_queue<int, std::vector<int>, std::greater<>> q;
    i64 res = 0;
    for (int n = 1; n <= N; n++) {
        if (A[n] <= A[n - 1]) {
            q.push(0);
            q.push(A[n] + K - A[n - 1]);
        } else {
            q.push(A[n] - A[n - 1]);
        }
        res += q.top();
        q.pop();
    }
    std::cout << res << "\n";
    
    return;
}
```

### [CF2119D](https://codeforces.com/contest/2119/problem/D) (DP)

[r-906 & Hatsune Miku - All I Can See Is You](https://www.youtube.com/watch?v=xv7hJ32xK94)

Define a sequence of integers $a$ valid if and only if $\forall 1 \le i \le n, 0 \le a_i \le i$.

Initially, a token is placed at each integer point in the closed segment $[1, n]$ on the number axis. Perform $n$ operations in sequence. During the $i$\-th operation, if $a_i \ne 0$, remove a token in the closed segment $[a_i, i]$ that has not been removed; otherwise, do nothing.

Find the sum of the number of ways to remove tokens over all $(n + 1)!$ valid sequences of length $n$.

```cpp
void solve() {
    std::vector<Z> f(N + 2, 1);
    for (int i = 1; i <= N; i++) {
        for (int j = N + 1; j >= i + 1; j--) {
            f[j] += f[j - 1] * (j - i) * i;
        }
    }
    std::cout << f[N + 1] << "\n";
}
```


### [CF1594F](https://codeforces.com/contest/1594/problem/F) (计算构造)

**题意**：考虑长度为 $N$ 的**正整数**数组 $a$，其所有元素之和为 $S$。如果**无论怎样构造**数组 $a$，都能找到一个和为 $K$ 的 **连续子数组**，输出 YES，否则输出 NO。$1 \leqslant S,N,K \leqslant 10^{18}$。

如果我们能找出一个数组，它不包含和为 $K$ 的连续子数组，就可以判 NO。下面我们研究这种情况。

结论：任意连续 $K$ 个数的和至少是 $2 K$。

结论的证明：

- 一方面，说明至少是 $2K$。考虑前缀和数组 $\{s_0, s_1, \dots, s_K\}$，依据鸽巢原理必然存在$s_j \equiv s_i \pmod K$，则 $s_j - s_i = m K$，根据要求连续子数组之和 $s_{j}-s_{i} \neq K$，因此 $s_{j}-s_{i} \geqslant 2K$，也就是说，任意连续 $K$ 个数的和至少是 $2 K$。
- 另一方面，说明 $2K$ 可以。$1, 1, \dots, (K+1)$。

不难将结论推广到整个数组。设带余除法 $N = K q + r$，构造 $q$ 个组，再补上 $r$ 个 1。形如  $1, 1, \dots, (K+1), 1, 1, \dots, (K+1), 1, 1$。

这些数的总和是 $2 K q + r$，因此如果 $S \geqslant 2 K q + r$ 就是 NO。此外需要特判 $S=K$。

```cpp
int main() {
    int T;
    std::cin >> T;    
    while (T--) {
        i64 S, N, K;
        std::cin >> S >> N >> K;        
        if (S == K) {
            std::cout << "YES\n";
        } else if (S >= N + N / K * K) {
            std::cout << "NO\n";
        } else {
            std::cout << "YES\n";
        }
    }
    return 0;
}
```



Given an array $A$ of length $N$ and an integer $V$.

Perform the following operation $M$ times:

1.  Choose an integer $i$ such that $1 \leq i \leq n$ uniformly at random.
2.  For all $j$ such that $i \leq j \leq n$, set $a_j := a_j + v$.

The expected value of $\prod_{i=1}^n a_i$ after performing the $m$ operations, modulo $10^9+7$.

设操作了 $c_{i}$ 次 $i$，我们求
$$
\begin{aligned}
S
&= \dfrac{1}{N^{M}}
\sum_{\sum c_{j} = M} 
\binom{M}{c_{1} \ c_{2} \ \dots \ c_{N}} 
\prod_{i=1}^{N} \Bigg( A_{i} + \sum_{j=1}^{i} c_{j} V \Bigg) 
\\
&= \dfrac{M!}{N^{M}} \sum_{S \subset [N]} V^{N - |S|}
\Bigg( \prod_{i \in S} A_{i} \Bigg) 
\sum_{1 \leqslant j \leqslant N, \sum c_{j} = M}
\dfrac{1}{\prod_{j=1}^{N} c_{j}}
\Bigg( \prod_{i \notin S} \sum_{j=1}^{i} c_{j} \Bigg)
\end{aligned}
$$


先帮我列写一个大纲，每部分写什么。注意我们不要求做一手调研，读论文就可以。

考虑 $\prod a_i$ 的组合意义，相当于有一个 $n+1$ 个点顺次连接形成的道路，一个人从第 $1$ 个点出发，从第 $i$ 个点走到第 $i+1$ 个点有 $a_i$ 种方案，问这个人走到 $n+1$ 共有多少种方案。 而修改的意义是什么呢，相当于在 $p$ 处放下了一个神奇妙妙工具，这个人走到 $p$ 的时候会拿起这个工具，之后对于任意的 $i$，可以选一个手上有的工具以 $v$ 的方案数从 $i$ 走到 $i+1$。 注意到被使用过的工具数量不超过 $n$，可以考虑在 DP 时记录这个状态，复杂度应该能降下来。 具体地，定义 $f_{i, j}$ 表示考虑了前 $i$ 处，使用了 $j$ 个工具的方案数，转移分三类： 1. 使用 $a_{i+1}$，$f_{i + 1, j} \gets f_{i, j} \cdot a_{i+1}$； 2. 使用一个被使用过的工具，$f_{i+1, j} \gets f_{i, j} \cdot j \cdot v$； 3. 使用一个还未被使用过的工具，需要先确定这个工具是哪里来的，$f_{i+1, j+1} \gets f_{i, j} \cdot (i+1) \cdot (m-j)\cdot v$。 最后的答案即为 $\sum\limits_i \frac{f_{n, i}}{n^i}$。

### [Disjoint Set Splitting](https://qoj.ac/contest/2559/problem/14418)

天才的题目。注意到存在 $k$ 满足 $c_{1}=\dots=c_{k}=1$，$c_{k+1}=\dots=c_{Q}=0$，假设所有的答案都是 1，我们来看看会发生什么。

- 当 $1 \le j \le k+1$ 时：计算第 $j$ 次查询时，依赖的历史真实答案为 $c_1, c_2, \dots, c_{j-1}$。由于此时 $j-1 \le k$，在真实情况下这些 $c_i$ 恰好全部等于 $1$，与假设所有答案都是 $1$ 的一致。因此解出的查询是完全正确，$(u'_j, v'_j) = (u_j, v_j)$。
- 这意味着，在处理到第 $k+1$ 次查询时，我们准确模拟了真实情况。且正是在处理完这第 $k+1$ 次真实查询后，图第一次变得不连通。
- 当 $j > k+1$ 时：查询被错误解码，但这已经不重要了。后续不断的删边操作不可能让图重新连通，因此直接断言后续 $c_{k+1} \dots c_Q = 0$ 即可。

### [Far Away](https://qoj.ac/contest/2559/problem/14421)

Randomization。

下面只考虑 $x$ 和 $y$ 在同一连通块内，且连通块大小超过 20000。

【做法】在连通块内，随机选取 300 个节点 $s$，运行单源 BFS，求出 $s$ 到连通块内所有其他节点的距离 `dis[s][x]`。

对查询 $(x, y)$，检查是否存在一个 $s$ 满足 `dis[s][x] + dis[s][y] <= 20000`。如果找到任何一个这样的 $s$，则 `NO`（距离小于等于 20000）；如果没有满足该条件的 $s$，则 `YES`。

【正确性】算法的唯一风险在于：$x$ 和 $y$ 真实距离 $\le 20000$，但我们随机抽取的 300 个点 $s$ 中，没有一个满足 `dis[s][x] + dis[s][y] <= 20000`。

事实上，无论图的结构如何，对于一个大小超过 20000 的连通块，只要 $x$ 和 $y$ 的连通距离 $\le 20000$，图中必然存在至少 10000 个 $s$ 满足 `dis[s][x] + dis[s][y] <= 20000`。（考虑最短路径以及路径外反方向的点）

总节点数 $N \le 100000$。每次在连通块中随机抽取一个节点，抽中满足条件 $s$ 的概率至少为 $P \ge \frac{10000}{100000} = 0.1$。算法独立随机抽取 300 次，一次都没有抽中的概率为 $(1-0.1)^{300}= 1.9 \times 10^{-14}$，可以认为不可能发生。

【复杂度】$\mathcal{O}(300 (N + M + Q))$。



## [CC-C](https://codeforces.com/gym/690768/problem/C)

- A hidden array $A$. 
- Except that two of its elements are $1$, all of the other elements are $0$.
- Task: to find the indices of the two elements of value $1$.
- Queries (No more than 20): In each query, you can choose a sub-sequence. Among these elements, if there is exactly one element whose value is $1$, the jury returns $1$; Otherwise, the jury returns 0.

```cpp
void CuteCube() {
    int N;
    std::cin >> N;
    
    unsigned diff = 0;
    for (int bit = 0; bit < 10; bit++) {
        std::vector<int> q;
        for (int n = 0; n < N; n++) {
            if (n >> bit & 1) {
                q.push_back(n);
            }
        }
        if (query(q)) {
            diff |= 1 << bit;
        }
    }

    unsigned ans = diff & -diff;
    int low_bit = std::countr_zero(ans);
    for (int bit = 0; bit < 10; bit++) {
        std::vector<int> q;
        for (int n = 0; n < N; n++) {
            if ((n >> bit & 1) && (n >> low_bit & 1)) {
                q.push_back(n);
            }
        }
        if (query(q)) {
            ans |= 1 << bit;
        }
    }
    std::cout << "! " << (ans ^ diff) + 1 << ' ' << ans + 1 << std::endl;
}
```

## [374E](https://codeforces.com/contest/374/problem/E)

在一个无限平面上，有 $N$ 个 A 类线段和 $M$ 个 B 类线段。在时间为 $t$ 时，A 类 $(x,y)$ 是一条以点 $(x-t, y+t)$ 和 $(x+t, y-t)$ 为端点的线段，B 类 $(x,y)$ 是一个以点 $(x+t,y+t)$ 和 $(x-t,y-t)$ 为端点的线段。寻找最小的 $t$，使得平面上至少有一个面积不为 $0$ 的矩形，矩形的每条边都应该至少被一条线段覆盖。

- 将坐标系旋转 $45^\circ$。对于平面上的任意一点 $(x, y)$，我们将其映射为新坐标 $(u, v)$，其中 $u = x - y$，$v = x + y$。A 类线段水平 $[x-y-2t, x-y+2t]$，B 类线段垂直 $[x+y-2t, x+y+2t]$。问题化为：在平面上存在若干水平线段和垂直线段，寻找最小的 $t$，使得它们能交织出一个四边平行于坐标轴的矩形。
- 二分 $t$。
- 合并同一行（列）的线段。
- 寻找矩形本质上是在寻找交点构成的四元环：

```cpp
for (int i = 0; i < b.size(); i++) {  // 垂直线
    auto [x, ly, ry] = b[i];
    std::vector<int> adj;
    for (int j = 0; j < a.size(); j++) {  // 水平线
        auto [y, lx, rx] = a[j];
        if (lx <= x && x <= rx && ly <= y && y <= ry) {
            adj.push_back(j); // (i, j) cross  记录穿过当前垂直线的水平线索引 j
        }
    }
    for (int j = 0; j < adj.size(); j++) {
        for (int k = j + 1; k < adj.size(); k++) {
            int u = adj[j]; // 穿过垂直线的第一条水平线索引
            int v = adj[k]; // 穿过垂直线的第二条水平线索引
            
            // 如果组合 (u, v) 已经在之前的某条垂直线中被标记过了
            // 说明有两条不同的垂直线，同时穿过了这两条水平线，矩形成立！
            if (vis[u][v]) return true; 

            // 标记这对水平线组合已被某条垂直线穿过
            vis[u][v] = true;
        }
    }
}
```
