### [Colorful Smile](https://codeforces.com/contest/2002/problem/E)

**题意** 你面前有一排 $n$ 个五颜六色的史莱姆，它们排成一队，每个的体积为 $v_{i}$，颜色为 $c_{i}$。随着时间的流逝，这些史莱姆都在慢慢融化，每秒钟它们的体积都会减少一点。当某个史莱姆的体积完全消失，它就会消失不见，而它旁边的两个史莱姆，如果颜色相同，就会像魔法一样融合在一起，变成一个更大的史莱姆，体积是它们两个的总和。

你的任务是，对于这一队史莱姆，计算出前 $i$ 个史莱姆全部融化并可能发生的融合之后，需要经过多少秒。这就像是观察一场缓慢而有趣的化学反应，你想知道对于每一个 $i$，这一切最终完成需要多长时间。

**思路** 如果 $v_{i} \leqslant v_{i+1}, c_{i} \neq c_{i+1}$，那么史莱姆 $i$ 便不可能产生贡献，因此有用的史莱姆序列有 $v_{i}>v_{i+1}$，用史莱姆维护这个序列。

```cpp
int n = read();

vector<Smile> sml;

for (int i = 0; i < n; i++) {
	ll v = read(), c = read();

	ll los = 0;    // 合并前的损耗
	while (!sml.empty()) {
		if (sml.back().c == c) {
			v += sml.back().v - los;
		}
		else if (sml.back().v <= v) {
			los = sml.back().v;
		}
		else {
			break;
		}
		sml.pop_back();
	}

	sml.emplace_back(v, c);

	printf("%lld ", sml[0].v);
}
```

### [CF2001D. Longest Max Min Subsequence](https://codeforces.com/contest/2001/problem/D)

**题意** 求正整数序列 $a$ 的每个元素恰好出现一次的子序列中，将奇数位置上的项乘以 $-1$ 后字典序最小的序列。数据范围：$1 \leqslant a_{i} \leqslant n \leqslant 3\times 10^{5}$。

**思路** 问题等价于最大化奇数位，最小化偶数位。

先考虑这样的问题：求每个元素恰好出现一次的子序列中字典序最小的序列。维护一个栈。从前向后遍历，如果新加入的元素比栈尾元素小，就将其弹出，以保证字典序最小。还有一个问题是可能弹出后这个元素就没有出现过了，故加上两个特判：
- 一是如果已经在栈中，就不做处理，用 `vis` 数组判断；
- 二是如果栈尾元素在序列中最后一次出现，就不弹出，用 `lst` 数组判断。

```cpp
void eachT() {
    int n = read();

    vector<int> a(n), lst(n);
    for (int i = 0; i < n; ++i) {
        a[i] = read() - 1;
        lst[a[i]] = i;
    }

    vector<int> vis(n);
    deque<int> stk;
    for (int i = 0; i < n; ++i) {
        if (vis[a[i]]) continue;
        while (!stk.empty() && a[stk.back()] > a[i] && lst[a[stk.back()]] > i) {
            vis[a[stk.back()]] = 0;
            stk.pop_back();
        }
        stk.push_back(i);
        vis[a[i]] = 1;
    }

    printf("%d\n", stk.size());
    for (int i = 0; i < stk.size(); ++i) {
        printf("%d ", a[stk[i]] + 1);
    }
    printf("\n");
}
```


回到原问题，与上面不同的是，需要依据栈的大小改变大于小于号，维护一个波浪形的栈。测样例后发现 `4 1 4 5 4 5 10 1 5 1`，错解为 `4 1 10 5`，正解为 `5 4 10 1`，栈中有 `4 1`，`5` 应该将这两个数都弹出后再入栈，但是按上面的写法 `1<5`，不用弹出，补上直接弹出栈尾的两个元素的情形就好了。

时空复杂度 $\Theta(n)$。

因为需要访问倒数第二个元素，没有用 `std::stack`。

```cpp
void eachT() {
    int n = read();

    vector<int> a(n), lst(n);
    for (int i = 0; i < n; ++i) {
        a[i] = read() - 1;
        lst[a[i]] = i;
    }

    int top = -1;
    vector<int> stk(n), vis(n);
    for (int i = 0; i < n; ++i) {
        if (vis[a[i]]) continue;
        while (top >= 0 && (top & 1 ? a[stk[top]] > a[i] : a[stk[top]] < a[i]) && lst[a[stk[top]]] > i) {
            vis[a[stk[top--]]] = 0;
        }
        while (top >= 1 && (top & 1 ? a[stk[top - 1]] < a[i] : a[stk[top - 1]] > a[i]) && lst[a[stk[top - 1]]] > i && lst[a[stk[top]]] > i) {
            vis[a[stk[top--]]] = 0;
            vis[a[stk[top--]]] = 0;
        }
        vis[a[stk[++top] = i]] = 1;
    }

    printf("%d\n", top + 1);
    for (int i = 0; i <= top; ++i) {
        printf("%d ", a[stk[i]] + 1);
    }
    printf("\n");
}
```

### 好消息，坏消息

给定一个环，判断有多少元素满足：所有以这个元素为起始的区间的和非负。([VJwin2C - 好消息，坏消息](https://www.luogu.com.cn/problem/P2629))





正解：单调队列

```cpp
const int N = 3e6 + 8;
int a[N], s[N];
void eachT() {
	int n = read();
	std::deque<int> q;
	for (int i = 1; i <= n; ++i) a[i] = read();
	for (int i = n + 1; i <= 2 * n - 1; ++i) a[i] = a[i - n];
	for (int i = 1; i <= 2 * n - 1; ++i) s[i] = s[i - 1] + a[i];
	int ans = 0;
	for (int i = 1; i <= 2 * n - 1; ++i) {
		while (!q.empty() && s[i] <= s[q.back()]) q.pop_back();
		while (!q.empty() && q.front() < i - n) q.pop_front();
		q.push_back(i);
		ans += (i > n - 1 && s[q.front()] - s[i - n] >= 0);
	}
	printf("%d\n", ans);
}
```

// 来自朱老师的“单调栈”方法
void eachT() {
    int n = 0, q = read(), mod = read(), t = 0;
    // s[]存的是a[]中单调降的序号 是单调增的
    // a[s[i]]-a[s[i+1]-1]中的最大值都是a[s[i]]
    int ss = 0; // s.size()
    while (q--) {
        char c; do c = getchar(); while (c != 'Q' && c != 'A');
        if (c == 'Q') {
            t = a[*lower_bound(s, s + ss, (n - read() + 1))]; // 二分搜下标 从后向前搜x个数即是正着数第n-x+1个数
            printf("%d\n", t);
        } else {
            a[++n] = (read() + t) % mod;
            while (ss >= 0 && a[n] > a[s[ss]]) --ss; // 维护单调栈
            s[++ss] = n; // 新数入栈
        }
    }
}
