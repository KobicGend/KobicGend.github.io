## 1007	划分

*绕了好几圈，好题。*

题目明说要递推计算，考虑多一个数有什么影响。利用左端点信息算右端点信息，不难写出 $dp_{r}=\max\limits_{l<r}\lbrace dp_{l} + (s_{r}\oplus s_{l})\cdot(r-l) \rbrace$，但这是 $\operatorname{O}(n^{2})$ 的。

注意值域范围 $<1024$，这东西比 $n$ 小。如果转移不枚举 $l$，转而枚举 $s_{l}$，就能实现 $\operatorname{O}(vn)$ 的复杂度。

将原式变形为 $dp_{l} - l\cdot(s_{r}\oplus s_{l})+r\cdot(s_{r}\oplus s_{l})$，现在需要知道哪个 $l$ 能使 $dp_{l}-l\cdot(s_{r}\oplus s_{l})$ 最大。不好弄，最难搞的问题是 $s_{r}$ 会变，$l$ 与 $r$ 不独立，没有办法在已知 $l$ 的时候就做出判断。既然会变，我们就枚举所有可能性，也即在已知 $l$ 时，枚举所有的 $b$，找 $dp_{l}-l\cdot(b\oplus s_{l})$ 的最大值。这问题就易做了，是一个典型利用左端点信息算右端点方案的问题。

```cpp
int n;
cin >> n;
vector mp(N, vector<ll>(N, -inf));
fill(mp[0].begin(), mp[0].end(), 0);
int s = 0;
ll res = 0;
for (int r = 1; r <= n; r++) {
	int x;
	cin >> x;
	s ^= x;
	ll dp = -inf;
	for (int i = 0; i < N; i++) {
		dp = max(dp, mp[i][s] + r * (s ^ i));
	}
	for (int i = 0; i < N; i++) {
		mp[s][i] = max(mp[s][i], dp - r * (s ^ i));
	}
	res += dp;
}
cout << res << endl;
```
