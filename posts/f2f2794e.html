Problem

Description

You are given a binary string SSS of length NNN.

Construct a directed graph based on this sequence: for any pair of indices (i,j)(i, j)(i,j), if Si=0S_i = 0Si​=0, Sj=1S_j = 1Sj​=1, and i<ji < ji<j, add a directed edge from node iii to node jjj.

这个图有很多性质：

  • VC：前缀 0 + 后缀 1，这个数量的最小值就是 MVC
  • IS：前缀 1 + 后缀 0

Initially, each node iii has a score of WiW_iWi​, represented by the array W=[W1,W2,…,WN]W = [W_1, W_2, \dots, W_N]W=[W1​,W2​,…,WN​]. You can perform the following two types of operations any number of times:

  1. Choose a node iii satisfying Si=0S_i = 0Si​=0: Node iii gives exactly 1 point to each of its adjacent nodes. As a result, the score of node iii decreases by its out-degree, and the score of each of its out-neighbors increases by 1.
  2. Choose a node jjj satisfying Sj=1S_j = 1Sj​=1: Node jjj takes exactly 1 point from each of its adjacent nodes. As a result, the score of node jjj increases by its in-degree, and the score of each of its in-neighbors decreases by 1.

In other words, the flow of points follows the direction of the edges in the graph.

Determine whether there exists a sequence of operations such that ultimately every node has a score of exactly 0 (i.e., Wi=0W_i = 0Wi​=0 holds for all iii).

Constraints

  • 2≤N≤1062 \le N \le 10^62≤N≤106
  • −109≤Wi≤109-10^9 \le W_i \le 10^9−109≤Wi​≤109

给定一个长度为 NNN 的 01 字符串 SSS。

根据该序列构造一个有向图：对于任意 (i,j)(i, j)(i,j)，如果 Si=0S_i = 0Si​=0、Sj=1S_j = 1Sj​=1，且 i<ji < ji<j，则添加一条从 iii 指向 jjj 的有向边。

初始时，每个节点 iii 都有一个分数值 WiW_iWi​，由数组 W=[W1,W2,…,WN]W = [W_1, W_2, \dots, W_N]W=[W1​,W2​,…,WN​] 表示。你可以执行以下两种操作任意次：

  1. 选择一个满足 Si=0S_i = 0Si​=0 的节点 iii：节点 iii 向其每个出边邻居各给予 1 分。
  2. 选择一个满足 Sj=1S_j = 1Sj​=1 的节点 jjj：节点 jjj 从其每个入边邻居各拿取 1 分。

换言之，分数流向就是图的箭头流向。

判断是否存在一种操作序列，使得最终每个节点的分数都恰好为 0（即对于所有 iii，均满足 Wi=0W_i = 0Wi​=0）。

Solution

特判：

  • 在第一个 0 之前的所有 1，初始分数 WiW_iWi​ 必须为 0。
  • 在最后一个 1 之后的所有 0，初始分数 WiW_iWi​ 必须为 0。
  • 总和 ∑Wi\sum W_i∑Wi​ 必须等于 0。

下面不妨设 S1=0,SN=1S_1=0,S_N=1S1​=0,SN​=1。

设 ViV_iVi​ 为节点 iii (Si=0S_i = 0Si​=0) 的操作次数，−Vj-V_j−Vj​ 为节点 jjj (Sj=1S_j = 1Sj​=1) 的操作次数。边 i→ji \to ji→j 上的流量为 Vi−VjV_i - V_jVi​−Vj​。每个节点的流量之和满足：

  • 若 Sk=0S_k = 0Sk​=0：Wk=∑j>k,Sj=1(Vk−Vj)W_k = \sum_{j > k, S_j = 1} (V_k - V_j)Wk​=∑j>k,Sj​=1​(Vk​−Vj​)
  • 若 Sk=1S_k = 1Sk​=1：Wk=∑i<k,Si=0(Vk−Vi)W_k = \sum_{i < k, S_i = 0} (V_k - V_i)Wk​=∑i<k,Si​=0​(Vk​−Vi​)

设 fk=∑i=1kWif_k = \sum_{i=1}^k W_ifk​=∑i=1k​Wi​ 为 WWW 的前缀和。

设 c0(k)c_0(k)c0​(k) 为前缀 S[1…k]S[1 \dots k]S[1…k] 中 0 的个数，c1(k)c_1(k)c1​(k) 为后缀 S[k+1…N]S[k+1 \dots N]S[k+1…N] 中 1 的个数。

将 WWW 从 111 累加到 kkk，所有内部的流量会相互抵消，只剩下跨越边界 kkk 的流量。我们得到：

fk=∑i=1kWi=c1(k)∑i⩽k,Si=0Vi−c0(k)∑j>k,Sj=1Vjf_k = \sum_{i=1}^k W_i = c_1(k) \sum_{i \leqslant k, S_i=0} V_i - c_0(k) \sum_{j>k, S_j=1} V_jfk​=i=1∑k​Wi​=c1​(k)i⩽k,Si​=0∑​Vi​−c0​(k)j>k,Sj​=1∑​Vj​

不妨假设 v1=0v_1 = 0v1​=0（因为 VkV_kVk​ 的绝对大小并不重要，整体加上一个常数 CCC 并不会改变流量 Vi−VjV_i - V_jVi​−Vj​，所以我们可以从左到右递推构造出一个相对数列 vkv_kvk​），并设 aka_kak​ 为直到下标 kkk 为止所有 0 对应的 viv_ivi​ 之和 (ak=∑i≤k,Si=0via_k = \sum_{i \le k, S_i=0} v_iak​=∑i≤k,Si​=0​vi​)。

通过代数变形，我们可以严格从左到右求解 vkv_kvk​：

  • 如果 Sk=0S_k = 0Sk​=0：

    vk=c1(k)ak−1+c0(k−1)Wk−fk−1c0(k−1)c1(k)v_k = \frac{c_1(k) a_{k-1} + c_0(k-1) W_k - f_{k-1}}{c_0(k-1) c_1(k)}vk​=c0​(k−1)c1​(k)c1​(k)ak−1​+c0​(k−1)Wk​−fk−1​​

    ak=ak−1+vka_k = a_{k-1} + v_kak​=ak−1​+vk​

  • 如果 Sk=1S_k = 1Sk​=1：

    ak=ak−1a_k = a_{k-1}ak​=ak−1​

    vk=Wk+ak−1c0(k)v_k = \frac{W_k + a_{k-1}}{c_0(k)}vk​=c0​(k)Wk​+ak−1​​

如果在任何一步计算中，分子 不能被分母整除，说明 vkv_kvk​ 不是整数（无法用离散次数的操作达成），直接输出 NO。

即使我们求出了整数序列 vkv_kvk​，我们还必须保证操作次数是非负的（xi≥0,yj≥0x_i \ge 0, y_j \ge 0xi​≥0,yj​≥0）。这隐含地要求每条边上的流量必须满足 Vi−Vj≥0V_i - V_j \ge 0Vi​−Vj​≥0。

因为我们已经证明了 Vi−Vj=vi−vjV_i - V_j = v_i - v_jVi​−Vj​=vi​−vj​，所以我们必须保证对于所有的 Si=0S_i = 0Si​=0 和所有的 Sj=1S_j = 1Sj​=1，都有 vi−vj≥0v_i - v_j \ge 0vi​−vj​≥0。

这等价于检查：

min⁡i:Si=0vi≥max⁡j:Sj=1vj\min_{i: S_i=0} v_i \ge \max_{j: S_j=1} v_ji:Si​=0min​vi​≥j:Sj​=1max​vj​

如果该不等式成立，输出 YES；否则输出 NO。
