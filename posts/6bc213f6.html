Non-overlapping Subsegments

發表於2026-06-12|更新於2026-06-15|邏輯與算法問題原創問題
|總字數:346|閱讀時間:2分鐘|瀏覽量:

Problem - E - Codeforces

Arseniy decided to make his friends Dabir and Egor happy. For this, he decided to give each of them an array of numbers of the same length. An array bbb is called good if its elements can be rearranged so that for all i>1i \gt 1i>1 the condition bi−bi−1=1b_i - b_{i - 1} = 1bi​−bi−1​=1 holds.

Arseniy wants Dabir and Egor to be able to play with these arrays. For this, the following conditions must be satisfied:

  1. Each of the given arrays is good.
  2. If you write one array after the other (in other words, concatenate them), the resulting array is also good.

Arseniy already has an array aaa of length nnn. He plans to cut both arrays from aaa, that is, to choose two non-overlapping subsegments of the same length. Help Arseniy determine the maximum possible length of the resulting arrays.
