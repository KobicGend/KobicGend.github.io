树上启发式合并与树上启发式合并

發表於2026-08-21|更新於2026-08-21|邏輯與算法知識
|總字數:3k

Aug.21

树上启发式合并用于解决「询问每个节点关于其子树的某些信息」的问题。

标题二者分别指

  • 树上启发式合并 (DSU on Tree)：专有名词，做法里需要删除轻子树
  • 树上启发式合并 (Small-to-Large)：把各个子树当作集合，按小给大合并两个集合容器

为避免歧义，下文分别以「DSU on Tree」与「Small-to-Large」称呼之。而「树上启发式合并」则表示这类通用思路。

* 启发式：基于人类的经验和直观感觉，优化算法

DSU on Tree

Idea

因简单的树形 DP 在空间上不能满足，所以不能存储每个节点的信息，而是要资源复用。

又因为在压缩空间后，需要对每个节点暴力统计子树的信息，在时间上又不能满足，所以 启发式地保留重子树的信息 ，以节约时间。

*DSU：并不存在真正的并查集结构，只是借用了 DSU 以启发式合并解决问题的名号（笑

Algorithm

加入重子树 →\rightarrow→ 加入轻子树 →\rightarrow→ 回答询问 →\rightarrow→ 删除轻子树

Complexity

假设数组修改为 O(1)\mathcal{O}(1)O(1)，DSU on Tree 的时间复杂度是标准的 O(Nlog⁡N)\mathcal{O}(N \log N)O(NlogN)。常数极小，可与二分、树状数组相媲美。

口胡证明：只有轻子树需要重新递归遍历修改，因此节点 xxx 的修改次数等于它到 root 的路径上轻边的数量，这不超过 ⌊log⁡2N⌋\lfloor \log_2 N \rfloor⌊log2​N⌋ 条。因此复杂度 O(Nlog⁡N)\mathcal{O}(N \log N)O(NlogN)。

Small-to-Large

Idea

启发式合并
有 NNN 个集合，欲按特定顺序将其合并，同时计算跨集合的信息。
做法：始终将较小集合的元素逐个取出，先在大集合中查询 / 计算与该元素的跨集合贡献，再将其插入大集合。

应用在树上，把各个子树当作集合。用小子树查大集合，算出不同子树之间的跨集合贡献。这里可以直接把轻子树合并到重子树的里面，就保证了每次都是小并大。

Algorithm

为每个节点维护一个容器，具体有两种写法：

  • 继承重子树的容器 →\to→ 遍历所有轻子树的容器逐个加入 →\rightarrow→ 回答询问
  • 不管轻重，直接比较容器大小 →\rightarrow→ 将较小集合的元素逐个加入较大的 →\rightarrow→ 回答询问

显然后者更好写，但前者有利于理解。

Complexity

使用 STL，时间复杂度为 O(Nlog⁡2N)O(N \log^{2} N)O(Nlog2N)。

口胡证明：任意一个元素每被移动一次，它所在集合的规模至少翻倍，因此每个元素至多被移动 O(log⁡N)O(\log N)O(logN) 次，而 set 等 STL 自带 log，总体时间复杂度为 O(Nlog⁡2N)O(N \log^{2} N)O(Nlog2N)，空间复杂度 O(N)O(N)O(N)。

多一个 log 这个事情可以上一个数据结构来解决。使用某些数据结构（如线段树合并），复杂度可能为 O(Nlog⁡N)\mathcal{O}(N \log N)O(NlogN) 或 O(Nlog⁡2N)O(N \log^{2} N)O(Nlog2N)，常数较大。

另外需要动态分配内存，空间常数也较大。

Comparison

本质都是保留重子树的贡献，只重新遍历 / 合并轻子树。

  • DSU on Tree：加入重子树 →\rightarrow→ 加入轻子树 →\rightarrow→ 回答询问 →\rightarrow→ 删除轻子树，复用全局数组。利用重新 DFS 访问 log⁡N\log NlogN 次保证复杂度。
  • Small-to-Large：继承重子树的容器 →\to→ 遍历所有轻子树的容器逐个加入 →\rightarrow→ 回答询问。利用至多合并 log⁡N\log NlogN 次保证复杂度。

实际上，DSU on Tree 是省去了 Small-to-Large 里「已计算、但暂时用不到」的那些轻子数的信息，转「存储」为「重算」。

最直白：

DSU on TreeSmall-to-Large
核心撤销、重算（需支持删除操作）存储、合并（保留每个子树历史状态）
数据结构无 / 树状数组（简单）STL / 线段树合并、主席树（复杂）
时间小大（常数或 log⁡\loglog）
空间小大
码量适中，模板较多STL 小，复杂数据结构大
在线 / 离线只能离线在线
